# ASB Skills: metagenomics

Evidence-grounded skill and software-tool collections for metagenomics, generated by the
[AgenticScienceBuilder](https://github.com/HolobiomicsLab/AgenticScienceBuilder) (ASB) pipeline
and released by the Holobiomics Lab. Each skill is distilled from a peer-reviewed method paper and its
public code repository, anchored to verbatim evidence, EDAM-annotated, and gated for licensing and
PII before release.

This repository holds the metagenomics collections only. The registry of every domain, the tooling,
the governance documents and the community contribution loop live in
[asb-skill-collections](https://github.com/HolobiomicsLab/asb-skill-collections).

## Status

No collection is released on `main` yet. A candidate lands on a branch named `candidate/<cut-id>`
with its receipts under `receipts/<cut-id>/`; it becomes a release when the owner merges it and tags
`v<major>.<minor>.<patch>`. No candidate has landed yet.

## Layout

A merged collection lives at `collections/metagenomics/<version>/`, router-shaped: the leaf skills under
`leaves/<slug>/SKILL.md`, one advertised router under `skills/_router/`, the indexes
(`skills_index.json`, `tools_index.json`, `kb_bundle.json`), the tool records under `tools/`, and the
source corpus in `corpus.yaml`. The tree shape is the one every ASB consumer resolves, so the shared
tooling works unchanged on this repository.

## Install

Claude Code, from a local checkout of a candidate branch or a release tag:

```bash
git clone --branch <branch-or-tag> https://github.com/HolobiomicsLab/asb-skills-metagenomics.git
claude plugin marketplace add ./asb-skills-metagenomics
claude plugin install metagenomics@asb-skills-metagenomics
```

## Provenance

Every candidate branch carries `receipts/<cut-id>/source.json`, naming the ASB commit, the
collections-tooling commit, the corpus commit, the per-paper view and the cut id, beside the strict
gate receipt (`gate_report.json`), the same-paper duplicate report and the output-to-leaf mapping.
Intent INT-ASB-043; pipeline specification `2026-09-18-domain-release-pipeline-design.md` in the
project hub.
