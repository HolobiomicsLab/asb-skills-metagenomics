# alignment-parameter-tuning

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

A threshold-sweep procedure for tuning sequence-alignment parameters: simulate reads with ART, align them against a reference database with Diamond blastx v2.0.8, and sweep identity/coverage cutoffs to find the combination that maximizes the retained hit rate. In the FunOMIC paper this identified read coverage >95%, identity percentage >99%, and e-value <10e-10 as optimal for fungal functional annotation against FunOMIC-P (~70% of fungal read hits retained).

## When to use

Use when building or validating an alignment/annotation pipeline and you need to empirically choose identity-percentage, read-coverage, and e-value cutoffs that maximize true positive mapping without inflating false positives.

## When NOT to use

- Input is real metagenomic data without ground truth — the sweep requires simulated reads with known species origin to compute true pass rates
- The task is taxonomic profiling against marker genes (FunOMIC-T with bowtie2 and >80% alignment length, q-score >30 filters), not translated functional annotation against a protein database
- Short-read aligners for nucleotide-level mapping are sufficient — Diamond blastx translated search is specific to protein-level functional annotation

## Inputs

- Coding gene sequences (protein/CDS) from a mock community of known species (e.g., top 20 fungal and top 20 bacterial species)
- Target protein-sequence database (e.g., FunOMIC-P, 3,413,239 non-redundant fungal proteins)
- Simulated Illumina FASTQ reads generated by ART

## Outputs

- Diamond blastx alignment hits per threshold combination
- Tab-separated table with one row per threshold combination (9 rows) and the fraction of simulated fungal reads whose hits pass the filters
- Selected optimal threshold set (coverage >95%, identity >99%, e-value <10e-10) with its pass rate (~70%)

## How to apply

Simulate Illumina-format reads from known ground-truth reference sequences (in FunOMIC, coding genes of the top 20 fungal and top 20 bacterial species of a mixed mock community) using ART. Align the simulated reads to the target database — FunOMIC-P, the 3.4 million non-redundant fungal protein database — using Diamond blastx v2.0.8 with a fixed e-value <10e-10 in every run. Sweep the nine combinations of identity percentage (>90%, >95%, >99%) crossed with read coverage (>90%, >95%, >99%), and for each combination compute the fraction of simulated fungal reads whose hits pass the filters. Record the nine pass rates in a single tab-separated table, one row per threshold combination, and select the combination with the highest retained fungal hit rate; high bacterial read leakage indicates thresholds are too permissive given inter-kingdom protein conservation.

## Related tools

- **Diamond blastx v2.0.8** (Aligns simulated reads to the FunOMIC-P protein database with e-value <10e-10; thresholds on identity and read coverage are applied to its output) — https://github.com/bbuchfink/diamond
- **ART** (Generates synthetic Illumina-format sequencing reads from mock community coding gene sequences to provide ground truth for the threshold sweep)
- **FunOMIC** (Source of the FunOMIC-P functional database and the pipeline context in which the tuned thresholds are applied) — https://github.com/ManichanhLab/FunOMIC

## Examples

```
diamond blastx -d FunOMIC-P.dmnd -q mock_simulated_reads.fq -e 1e-10 -o hits.tsv
```

## Evaluation signals

- The result table contains all nine threshold combinations (3 identity levels x 3 coverage levels), one row each
- The combination with read coverage >95% and identity percentage >99% shows the highest retained fungal read hit rate (~70%), confirming it as optimal
- Every run used the same fixed e-value cutoff (<10e-10), so pass-rate differences are attributable to identity/coverage filters alone
- Bacterial simulated reads show minimal alignment to FunOMIC-P at the chosen strict threshold, consistent with the paper's specificity analysis (specificity 0.9999 at the taxonomic level)
- Pass rates are monotone-decreasing as thresholds tighten (e.g., >90/90 gives more retained hits than >99/99)

## Limitations

- High inter-kingdom conservation of protein-coding genes means bacterial contamination was not totally preventable, even after applying the exceedingly strict mapping threshold to fungal functional annotation
- No bacterial read filtration step is included before functional annotation; the paper only proposes adding it in a future update
- Even the optimal combination retains only ~70% of fungal read hits, so strict thresholds trade sensitivity for specificity
