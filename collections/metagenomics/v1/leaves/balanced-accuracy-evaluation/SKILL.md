# balanced-accuracy-evaluation

## Summary

Evaluate PICA/libSVM-based phenotypic trait classifiers using balanced accuracy computed from repeated 5-fold cross-validation, so that trait predictions remain reliable on imbalanced phenotype classes. This metric is the basis for the paper's SVM kernel comparison and genome-completeness response curves.

## When to use

Use when comparing SVM kernels or training-set variants for binary phenotypic trait prediction (e.g. gram-negative status, spore-forming, phototrophy) on COG presence/absence matrices and you need a class-imbalance-robust performance metric.

## When NOT to use

- The task is multi-class phenotyping or regression rather than binary trait classification — balanced accuracy as used here is defined for PICA's binary SVM trait models
- Features are not comparative-genomics presence/absence vectors (e.g. expression or sequence-only data) — the paper's evaluation is tied to COG-based trait prediction
- A pre-trained phenotrex/PhenDB model is already curated for the trait; the README directs users to PhenDB rather than re-training and re-scoring

## Inputs

- COG presence/absence feature matrices (eggNOG 4.0) for reference genomes from the PICA distribution
- Phenotypic trait labels for the ten example traits (e.g. gram-negative, spore-forming, phototrophy, psychrophily)
- Simulated incomplete genomes generated by random gene removal at defined completeness levels

## Outputs

- kernel_balanced_accuracy.csv with one row per trait and one column per SVM kernel
- accuracy_vs_completeness.csv with balanced accuracy per trait and completeness level
- trait_accuracy_curves.png with per-trait balanced-accuracy response curves

## How to apply

Train one binary classifier per phenotypic trait with PICA's libSVM-based SVM plug-in, using the eggNOG 4.0 COG presence/absence feature matrix as features and trait labels as targets. Evaluate each classifier with 5-fold cross-validation repeated 10 times, recording balanced accuracy per replicate, then aggregate replicates into a mean balanced accuracy per trait. For kernel comparisons, repeat the identical 5-fold x 10-replicate protocol for linear, RBF, sigmoid, and polynomial kernels and tabulate results per trait (e.g. kernel_balanced_accuracy.csv). For completeness experiments, simulate incomplete genomes by randomly removing genes from held-out genomes across completeness levels, predict traits, and compute balanced accuracy per trait at each level to build sigmoidal response curves (accuracy_vs_completeness.csv, trait_accuracy_curves.png). Balanced accuracy is chosen because it fairly scores imbalanced phenotype classes, which is the paper's criterion for judging kernels and trait predictability.

## Related tools

- **PICA** (Framework used to train the per-trait binary classifiers and run the cross-validation evaluation) — github.com/univieCUBE/PICA
- **PICA support vector machine plug-in** (SVM plug-in whose linear, RBF, sigmoid and polynomial kernels are compared by balanced accuracy) — github.com/univieCUBE/PICA
- **libSVM** (Underlying SVM library invoked by the PICA plug-in during cross-validation)
- **phenotrex** (Successor package of PICA offering updated classifiers and trait prediction via CLI; relevant for reimplementing the evaluation) — https://github.com/univieCUBE/phenotrex

## Examples

```
$ phenotrex predict --classifier MY_TRAIT.pkl genome.fna > predictions.tsv
```

## Evaluation signals

- Linear kernel's mean balanced accuracy is >= that of RBF, sigmoid, and polynomial kernels for all ten traits, reproducing the kernel-comparison outcome
- Balanced-accuracy response curves reach near-maximal accuracy for most traits at 60-70% genome completeness
- Gram-negative status remains predictable at 30-40% completeness while psychrophily stays difficult even at 100% completeness
- Per-replicate balanced accuracy values are recorded for all 10 x 5-fold x 10-replicate combinations before aggregation
- Output tables contain one row per trait with one column per kernel (or per completeness level) and no missing trait entries

## Limitations

- Most traits can be reliably predicted only in 60-70% complete genomes, so predictions for more fragmented metagenomic bins are not supported
- Trait predictability varies: psychrophily remains difficult even with complete genomes, while spore-forming and phototrophy only improve above ~70% completeness
- PICA is superseded by phenotrex; the README notes the successor builds on scikit-learn with new classifiers such as XGboost
- Performance for further ecologically important traits depends on availability of sufficient training data
