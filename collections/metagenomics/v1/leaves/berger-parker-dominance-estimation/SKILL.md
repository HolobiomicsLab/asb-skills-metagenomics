# berger-parker-dominance-estimation

## Summary

Compute the Berger-Parker dominance index (relative abundance of the single most abundant taxon) per sample in 16S rRNA amplicon profiles, before and after CopyRighter 16S gene copy number (GCN) correction, to quantify how lineage-specific GCN bias skews dominance estimates.

## When to use

Use when amplicon OTU tables (e.g. Greengenes-based twin gut cohort profiles) are being corrected with CopyRighter and you must verify that per-sample dominance changes fall in a reported range (0-23.3%) or summarize community dominance shifts.

## When NOT to use

- Input profiles are already relative abundances (percentages) — CopyRighter requires raw read counts, so dominance correction on pre-normalized data is invalid
- The community profile was generated by shotgun metagenomics without genome-length trait estimates rather than 16S rRNA amplicons, or uses a taxonomy other than Greengenes (e.g. Silva), which CopyRighter does not yet cover
- You only need generic alpha diversity and have no need to assess GCN-bias effects on dominance

## Inputs

- Sample-by-taxa OTU count table in biom, QIIME, GAAS, Unifrac, or generic tabular format, containing read counts (not percentages) with unaltered Greengenes taxonomic strings
- CopyRighter phylogenetic GCN estimate file for Greengenes OTUs and taxa (e.g. selected via the COPYRIGHTER_DB environment variable)

## Outputs

- Per-sample Berger-Parker dominance values before correction
- Per-sample Berger-Parker dominance values after CopyRighter correction
- Per-sample dominance differences validated against the reported 0-23.3% range

## How to apply

Start from the sample-by-taxon count table (biom/QIIME/generic tabular format) and run CopyRighter with phylogenetic-level correction, weighting each taxon's read counts by the inverse of its lineage-specific 16S rRNA GCN from the Greengenes data files shipped with the tool. For each sample, both uncorrected and corrected, compute the Berger-Parker dominance index as the relative abundance of the most dominant taxon. Report the per-sample difference (corrected minus uncorrected) and check that differences span the reported 0-23.3% range in the twin gut cohort (280 samples with >=1,000 reads). Use the corrected index alongside phylum medians (Bacteroidetes 21.7%, Firmicutes 76.0%) and enterotype reclassification (23.9% of samples) as validation signals that the GCN correction was applied correctly.

```

```

## Evaluation signals

- Per-sample Berger-Parker differences (corrected minus uncorrected) fall within the reported 0-23.3% range on the twin gut cohort (280 samples with >=1,000 reads)
- Corrected phylum-level medians match Bacteroidetes 21.7% and Firmicutes 76.0% within reasonable tolerance
- Input table contains raw read counts, not percentages, with unaltered Greengenes taxonomic strings (e.g. 'k__Bacteria; p__Proteobacteria; ...; s__siberiense')
- CopyRighter runs in verbose mode (-v) show trait (GCN) value assignments resolved as intended via phylogenetic-level lookup
- Corrected enterotype assignment partitions samples into three rather than two types, with 23.9% of samples misclassified without correction

## Limitations

- GCN bias correction effects are non-trivial to predict because communities often contain tens to thousands of species
- CopyRighter GCN estimates currently cover only the Greengenes taxonomy; other taxonomies (e.g. Silva) are not yet supported
- CopyRighter correction is limited to 16S rRNA gene copy number; GC percent, genome length, and fungal ITS variation correction is only hypothetical pending appropriate pre-computed estimates
- No version of CopyRighter beyond the README's copyrighter version 0.46 is stated in the article discussion
