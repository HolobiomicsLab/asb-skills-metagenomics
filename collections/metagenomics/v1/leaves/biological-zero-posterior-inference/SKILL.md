# biological-zero-posterior-inference

## Summary

Computes, for every observed zero in a longitudinal OTU table, the posterior probability that it is a biological zero (taxon absent from the community) versus a technical zero (taxon present but below detection threshold) using LUMINATE's variational inference with forward-backward HMM updates of the hidden state q(w_t^d).

## When to use

Use when longitudinal count data contain many zeros and the analysis must decide whether a taxon is truly extinct from the community or merely under the sequencing detection threshold.

## When NOT to use

- The dataset contains ultra-sparse taxa (>90% missing/zero entries) — these should be filtered out as a pre-processing step because there is little information to reconstruct their trajectory over time.
- The data are cross-sectional (single time point) rather than longitudinal; LUMINATE pools information across longitudinal samples of a time series.
- The goal is to model external perturbations such as antibiotics affecting zero status — the paper explicitly lists this as future work, not supported by the current framework.

## Inputs

- OTU table (taxa by samples) as CSV with first row = longitudinal sequence IDs, second row = sample times, first column = taxon names (e.g. datasets/bucci2016mdsine/cdiff-counts.csv)
- Optional external perturbations CSV with columns sequenceID,eventID,startDay,endDay,magnitude(optional)

## Outputs

- cdiff-counts-est.csv : denoised estimated relative abundances
- cdiff-counts-nonzero-posterior-prob.csv : posterior probabilities that each observed zero is a sampling (technical) zero
- P.pkl : temporary result used for downstream analysis
- biological_zero_posterior_probabilities.csv : per-zero posterior biological-zero probabilities aggregated across replicates (simulation workflow)

## How to apply

Run LUMINATE's `estimate` command on a taxa-by-samples OTU table (first row = sequence IDs, second row = sample times, first column = taxon names; optional `-e` events CSV with columns sequenceID,eventID,startDay,endDay,magnitude) to obtain denoised relative abundances (`*-est.csv`) and the hidden-state variables w. For each observed zero, LUMINATE computes the posterior probability q(w_t^d = 0) via variational inference with forward-backward HMM updates. The README output `cdiff-counts-nonzero-posterior-prob.csv` gives posterior probabilities of sampling zeros, i.e. that a taxon is below the detection threshold as opposed to absent; 1 minus this quantity is the biological-zero probability. In the paper's validation, posterior probabilities were computed across 10 simulated gLV datasets (4 taxa, 30 days, 10 longitudinal samples each, generated by simulate_glv_with_zeros.py with one extinct taxon, one near the detection threshold, and two abundant), aggregated into biological_zero_posterior_probabilities.csv, and evaluated by AUC-ROC (mean = 0.91, std = 0.04). As pre-processing, filter out ultra-sparse taxa (>90% missing entries) since there is little information about their trajectory over time.

## Examples

```
python main.py estimate datasets/bucci2016mdsine/cdiff-counts.csv -e datasets/bucci2016mdsine/cdiff-events.csv -o datasets/bucci2016mdsine
```

## Evaluation signals

- Posterior biological-zero probabilities separate the true zeros (extinct taxon) from the technical zeros (taxon near detection threshold) in the simulated gLV data.
- Mean AUC-ROC across all 10 simulated replicates should be high (paper reports mean = 0.91, std = 0.04).
- Running `plot` on the produced `*-est.csv` should yield plausible denoised stacked-bar trajectories with no obvious artifacts.
- All three estimate outputs exist: *-est.csv, *-nonzero-posterior-prob.csv, and P.pkl in the --outdir directory.
- The 2-to-1 ratio of true zeros versus technical zeros in the simulation (one extinct, one near-threshold, two abundant taxa) is reflected in bimodal posterior probabilities.

## Limitations

- Ultra-sparse taxa (>90% missing entries) carry too little information for reliable trajectory reconstruction and should be filtered out before inference.
- The biological zero detection framework does not yet include external perturbations such as antibiotics (listed as future work in the discussion).
- Downstream analysis of biological interaction networks among taxa is not yet implemented (future work).
