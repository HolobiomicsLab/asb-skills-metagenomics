# biosample-taxonomy-classification

## Summary

Attach taxonomic identity metadata to ENA BioSample accessions recovered from COBS query hits and tally how many samples come from isolates with known taxonomy, spanning how many distinct genera and species — as done when tracing ISC insertion sequence hits back to 661,405 microbial genomes.

## When to use

Use when you have positive genome hits (e.g. from COBS queries against a compact index of ENA bacterial genomes) mapped to BioSample accessions and need to classify them by isolate taxonomy and count distinct known genera and species.

## When NOT to use

- Your input is raw reads or contigs rather than already-mapped BioSample-level genome hits — taxonomy classification here presupposes a parsed COBS hit list
- You need novel IS discovery or ITR identification from metagenomic reads — that is Palidis's role, not this metadata-classification step
- The BioSamples lack any associated taxonomic metadata, leaving nothing to classify or count

## Inputs

- COBS query output mapping positive genome hits to ENA BioSample accessions (e.g. 155 ISs across 791 BioSamples from the 661k.cobs_compact index)
- Taxonomic identity metadata for the positive ENA BioSample accessions (genus/species labels per isolate)

## Outputs

- Per-IS isolate occurrence table (isolate occurrence per insertion sequence with taxonomy)
- Summary counts table (isolate_query_summary.tsv): number of taxonomically identified BioSamples and distinct known genera and species

## How to apply

After parsing COBS output (run with threshold -t 0.9, so only genomes with at least 90% of an IS's k-mers present are reported) to map each positive genome hit to its ENA BioSample accession, join the BioSample accessions to their taxonomic identity metadata. Tally how many samples have an associated taxonomic identity versus unknown ('sp.') labels, then count distinct genera and distinct species among the identified samples, excluding species labelled only as 'sp.'. Write the per-IS isolate occurrence table and summary counts (e.g. 791 BioSamples, 684 taxonomically identified, 63 genera, 138 species) to a summary file such as isolate_query_summary.tsv and verify the reproduced counts match reported values.

## Examples

```
cobs query -t 0.9 --file-contains --index 661k.cobs_compact --query ISC.fasta > cobs_hits.tsv
```

## Evaluation signals

- COBS parsing stage should recover the expected 155 distinct ISs across 791 distinct BioSamples before taxonomy attachment
- Taxonomically identified sample count should match the reported 684 of the 791 BioSamples
- Distinct known genera count should equal 63 and distinct species (excluding 'sp.' labels) should equal 138
- isolate_query_summary.tsv rows should reconcile with the per-IS hit table (each taxonomically identified sample appears under exactly one BioSample accession)
- Reproduced counts must match the paper's reported values exactly (155 ISs, 791 BioSamples, 684 identified, 63 genera, 138 species)

## Limitations

- Samples whose isolate has no associated taxonomic identity (or is only labelled 'sp.') cannot be assigned to a known genus or species and are excluded from the known genera/species tallies
- The underlying ISC v1.0.0 was built only from healthy human oral cavity and stool metagenomes, so taxonomic origin tracing is biased toward isolates from those sources
- COBS hits at threshold -t 0.9 reflect k-mer presence, not direct isolation source — horizontal gene transfer means an IS hit does not guarantee the queried genome is the IS's original source
