# de-novo-genome-assembly

## Summary

Whole-genome de novo diploid assembly of 10x Linked-Read data using 10x's Supernova2, applied to both simulated (LRTK-SIM) and real libraries, followed by extraction of contiguity metrics (contig/scaffold N50) and accuracy metrics (NA50) to assess assembly quality as a function of library parameters.

## When to use

Use when paired-end gzipped FASTQ from 10x Chromium Linked-Read libraries (real or LRTK-SIM simulated) must be assembled de novo and contiguity/accuracy compared across coverage (C, CF, CR) or fragment-length conditions.

## When NOT to use

- The goal is comparison of assemblers other than Supernova2 — the study notes that until another comparable assembler exists, fragment-length effects cannot be reasoned about
- The input data are not barcode-linked short reads (e.g. long PacBio/ONT reads), which this Linked-Read assembly workflow does not cover
- Assembly evaluation requires accuracy metrics but no high-quality reference genome exists — NA50 comparison was only possible because a high-quality human reference genome exists

## Inputs

- Paired-end gzipped 10x Linked-Read FASTQ files (X_S1_L001_R1_001.fastq.gz, X_S1_L001_R2_001.fastq.gz) per library
- Diploid reference FASTA pair generated by gen_fasta.py (hg38 plus SNVs from a VCF) for simulation and NA50 computation
- LRTK-SIM configuration files specifying CF, CR, N_FP, Mu_F, SR, Mu_IS, Std_IS, Error_rate, and Hap

## Outputs

- Supernova2 diploid whole-genome assembly per library
- Contig and scaffold N50 contiguity metrics per assembly
- NA50 accuracy metrics computed against the reference per assembly

## How to apply

Assemble each Linked-Read library (paired FASTQ files X_S1_L001_R1_001.fastq.gz and X_S1_L001_R2_001.fastq.gz) with Supernova2, the assembler emphasized by this study. For simulated data, first generate two haploid diploid references with gen_fasta.py (inserting SNVs from a VCF into the hg38 reference; SNVs only) and simulate libraries with LRTK-SIM by setting config parameters: CF (line7, physical coverage), CR (line9, read coverage per fragment), Mu_F (line13, mean fragment length in Kb), Hap=2 (line33), plus Mu_IS, Std_IS, and Error_rate. Run Supernova2 de novo assembly on each library, then compute contig and scaffold N50 for contiguity and NA50 against the reference for accuracy. Judge quality by the study's reported ranges: contig N50 rising from 621.4 to 758.1 kb and NA50 from 587.5 to 713.3 kb as total coverage C increases from 16x to 78x, with broadly optimal parameters yielding ~80% of the genome in diploid state.

## Related tools

- **Supernova2** (De novo diploid whole-genome assembler applied to each simulated and real 10x Linked-Read library)

## Examples

```
python LRTK-SIM.py ./diploid_config
```

## Evaluation signals

- Contig and scaffold N50 increase monotonically with total coverage C, reproducing the reported contig N50 shift from 621.4 to 758.1 kb beyond C = 56x (simulation)
- NA50 accuracy shifts from 587.5 to 713.3 kb over the same coverage increase
- At constant C = 56x, contig N50 decreases with increasing fragment length (Mu_F) and with increasing physical coverage CF
- Optimal CF window falls between 332x and 823x, with quality worsening above 1,000x; optimal W_mu_FL is ~50-150 kb
- With broadly optimal parameters, ~80% of the genome is assembled in a diploid state

## Limitations

- gen_fasta.py supports SNVs only when inserting variants into the reference genome
- Only ~20-40% of the original long fragment sequence is captured per partition by the 10x Chromium system due to partition-level amplification
- NA50 accuracy assessment relies on an existing high-quality human reference genome; otherwise N50 alone is misleading
- Including extremely long fragments is detrimental for assembly quality, possibly due to loss of barcode specificity for fragments spanning repetitive sequences, though this explanation is unverified
