# deep-residual-network-training

## Summary

Train DeepECA's deep residual network (up to 60 residual layers with batch normalization) end-to-end on multiple sequence alignments for protein contact, secondary structure, and solvent accessibility prediction, using the multitask.py training script.

## When to use

Use when training a DNN to predict protein contacts and secondary structure from raw MSAs end-to-end, rather than from precomputed covariance or precision-matrix features.

## When NOT to use

- When a pre-trained DeepECA model suffices — use pipeline.py for prediction instead of retraining from scratch
- When only shallow MSAs are available without the option to add sequential/derived features, since the paper notes accuracy gains depend on MSA depth and weighting
- When input is already a covariance or precision matrix (e.g., PSICOV output) — DeepECA takes the raw MSA as its input feature source

## Inputs

- MSAs generated by HHblits (three iterations, E-value 0.001, 60% coverage, UniProt20_2016)
- Training protein FASTA files placed in ./dataset/fasta
- Training datasets and pre-trained model files from the DeepECA Google Drive folder
- Contact labels defined as Cβ–Cβ distance < 8 Å (Cα for glycine)

## Outputs

- Trained multitask residual-network model weights
- Contact prediction files in ./contact_pred
- Secondary structure and ASA prediction files in ./ss_pred

## How to apply

Download the training datasets and pre-trained model files from the DeepECA Google Drive folder, then generate MSAs with HHblits (three iterations, E-value 0.001, 60% coverage, UniProt20_2016 library) after setting the hhblits path in run_hhblits_local.py. Train by running multitask.py: the network uses a 20-residual-block shared trunk plus task-specific 10-block heads, ADAM optimizer at learning rate 0.0005, batch normalization, one domain per batch, cropping 200 residues per protein, and sampling up to 30,000 MSA sequences when deeper. Expect approximately 2-3 days on an NVIDIA TITAN GTX GPU; 60 layers was the depth limit imposed by GPU memory. After training, run pipeline.py so predictions land in ./contact_pred and ./ss_pred directories.

## Related tools

- **DeepECA** (Framework containing the residual-network architecture and multitask.py / pipeline.py training and prediction scripts) — https://github.com/tomiilab/DeepECA
- **HHblits** (Generates the input MSAs (three iterations, E-value 0.001, 60% coverage) consumed by the network during training)
- **TensorFlow** (Deep-learning backend (r1.11.0) in which the residual blocks are implemented)

## Examples

```
python multitask.py  # then: python pipeline.py
```

## Evaluation signals

- Contact prediction accuracy at every distance bin and prediction count exceeds the unweighted Baseline Model on the validation dataset (Table 2)
- Secondary-structure accuracy outperforms RaptorX-Property and SCRATCH-1D on CASP11 (105 domains) and CASP12 (55 domains) (Tables 4-5)
- ASA prediction accuracy is highest among the three compared methods on CASP11 and CASP12 (Table 6)
- Prediction files appear in both ./contact_pred and ./ss_pred after running pipeline.py
- Training completes within roughly 2-3 days on an NVIDIA TITAN GTX GPU without exceeding GPU memory at 60 layers

## Limitations

- GPU memory limits the network to 60 layers
- Training requires a GPU and takes 2-3 days on an NVIDIA TITAN GTX
- TensorFlow r1.11.0 on Ubuntu 16.04 is the tested environment; other versions may not work
- Residue pairs with missing Cβ coordinates must be marked NaN and excluded from the loss calculation
