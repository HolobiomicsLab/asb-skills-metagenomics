# false-positive-rate-quantification

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Quantifies cross-kingdom false-positive mapping of a taxonomic database by simulating bacterial reads (ART), aligning them to a fungal-only database (FunOMIC-T) via bowtie2 with strict samtools filters (>80% read-length alignment, q-score >30), and computing mapping rate and specificity.

## When to use

Use when validating that a taxonomic marker-gene database (e.g., fungal FunOMIC-T) does not erroneously map sequences from off-target organisms, by measuring bacterial mapping rate and specificity on simulated mock-community reads.

## When NOT to use

- Evaluating the functional database FunOMIC-P, where high inter-kingdom conservation of protein-coding genes means bacterial contamination is not totally preventable even with strict thresholds (coverage >95%, identity >99%, e-value <10e-10)
- Profiling real mycobiome samples rather than benchmarking database specificity — use the full FunOMIC pipeline with bacterialDB screening instead
- Input reads are real (non-simulated) metagenomic data where true bacterial read labels are unknown, making false-positive counting impossible

## Inputs

- FunOMIC-T taxonomic database (1.69 million fungal single-copy marker genes) from https://manichanh.vhir.org/funomic/
- Bacterial genome collection from NCBI (e.g., 903 genomes / 458 species inhabiting the human body)
- Mock community genome composition (Supplementary Table S1: top 20 fungal and top 20 bacterial species from 2,679 human metagenomes)
- Simulated Illumina-format FASTQ read sets generated by ART (bacterial-only and mixed mock communities)

## Outputs

- Bacterial mapping rate to FunOMIC-T for the 903-genome bacterial mock community (<0.01% expected)
- Specificity value for the mixed mock community (false positive / (false positive + true negative); 0.9999 expected)
- validation_metrics.csv containing the computed metrics

## How to apply

Simulate Illumina-format reads with ART from bacterial genomes collected from NCBI (e.g., 903 genomes from 458 human-associated bacterial species), either as a bacterial-only mock community (~19,301,201 reads) or as a mixed bacterial:fungal mock community with a ~1000:1 read ratio (~999,021 bacterial reads) using the genome composition from Supplementary Table S1. Align both simulated read sets to the FunOMIC-T database (1.69 million fungal single-copy marker genes) through the FunOMIC pipeline using bowtie2, retaining mapped reads only when more than 80% of the read length aligns with a q-score over 30 (samtools filtering). Compute the bacterial mapping rate for the bacterial-only community, and specificity as false positives / (false positives + true negatives) for the mixed community. The database passes validation when specificity reaches 0.9999 (zero of 999,021 bacterial reads aligning) and the bacterial-only mapping rate stays below 0.01%.

## Related tools

- **ART** (Simulates synthetic Illumina-format sequencing reads from the 903 bacterial genomes and the mixed mock community composition)
- **bowtie2** (Aligns simulated bacterial reads to the FunOMIC-T fungal marker-gene database within the FunOMIC pipeline) — http://bowtie-bio.sourceforge.net/bowtie2/index.shtml
- **samtools** (Filters mapped reads, keeping only alignments covering >80% of read length with q-score over 30) — http://www.htslib.org/
- **FunOMIC** (Pipeline hosting the FunOMIC-T database and bowtie2/samtools mapping workflow used for the specificity test) — https://github.com/ManichanhLab/FunOMIC

## Examples

```
FunOMIC.sh -1 bacterial_mock_R1.fastq -2 bacterial_mock_R2.fastq -p bact_mock -o out -a bacterialDB_path -b FunOMIC-T_folder -c FunOMIC-P_folder -t 8
```

## Evaluation signals

- Mixed mock community: none of the 999,021 simulated bacterial reads align to FunOMIC-T, giving specificity = false positive / (false positive + true negative) = 0.9999
- 903-genome bacterial mock community (19,301,201 simulated Illumina reads) shows a mapping rate below 0.01% to FunOMIC-T
- Mapped-read filter is correctly applied: only alignments spanning more than 80% of read length with q-score over 30 are retained
- Mixed mock community composition matches the ~1000:1 bacterial:fungal read ratio built from the top 20 fungal and top 20 bacterial species
- Computed metrics are written to validation_metrics.csv and reproduce Supplementary Table S1-based expected values

## Limitations

- Specificity of the taxonomic database depends on the completeness of available fungal genomes, which limits taxonomic coverage relative to amplicon databases
- Strict mapping thresholds suppress but may not fully eliminate cross-mapping; for FunOMIC-P functional annotation, bacterial contamination is not totally preventable due to high inter-kingdom conservation of protein-coding genes
- No bacterial read filtration step exists before functional annotation; it is only proposed for a future update of the tool
