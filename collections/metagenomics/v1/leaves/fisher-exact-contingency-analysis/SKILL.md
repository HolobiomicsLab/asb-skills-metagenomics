# fisher-exact-contingency-analysis

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Two-by-two Fisher's exact test on the counts of significantly enriched biological pathways (P<0.05) shared between OMARU's metagenome (MWAS) pathway association results and host GWAS pathway enrichment results, quantifying disease-specific metagenome–genome links for SCZ and T2D.

## When to use

Use when both an OMARU MWAS pathway enrichment file (sumstats_*_annot.txt) and a PASCAL-derived GWAS pathway enrichment file (<Phenotype>_GWAS_<Pathway_reference>.txt) exist for the same phenotype and you must quantify their pathway-level overlap.

## When NOT to use

- You only have raw GWAS SNP-level summary statistics — pathway-level GWAS enrichment must first be produced (e.g. via PASCAL) before overlap testing is meaningful
- You want to test overlap of taxa/clade-level phylogenetic associations rather than biological pathway enrichment results
- No MWAS pathway enrichment results are available because the gene-level association and pathway annotation steps (OMARU_Func_AS.sm / OMARU_Func_permutation.sm) have not been run

## Inputs

- OMARU MWAS pathway enrichment summary statistics: sumstats_*_annot.txt from <OMARU_project_dir>/result/FUNC_QCed3 (produced via Snakefiles/OMARU_Func_permutation.sm)
- GWAS pathway enrichment file <Phenotype>_GWAS_<Pathway_reference>.txt (column 1 = pathway ID, column 2 = p-value), generated by PASCAL on SCZ GWAS summary statistics (22,778 cases / 35,362 controls) and T2D GWAS summary statistics (77,418 cases / 433,544 controls)
- Significance threshold P<0.05 (PQ parameter in config.yaml)

## Outputs

- 2x2 contingency tables of MWAS-significant / GWAS-significant pathway counts per phenotype (SCZ and T2D separately)
- Fisher's exact test P-values saved to MWAS_GWAS_pathway_overlap_PFisher.tsv (expected 0.011 SCZ, 0.008 T2D)
- Tables and figures of MWAS–GWAS pathway links in <OMARU_project_dir>/result/FUNC_QCed3/MWAS_GWAS/<Pathway_reference> (via OMARU_Func_MWAS_GWAS.sm)

## How to apply

Load the OMARU gene/pathway abundance association outputs (sumstats_*_annot.txt from Snakefiles/OMARU_Func_permutation.sm) for the SCZ (n=344) and T2D (n=171) cohorts, and the GWAS pathway files with pathway ID in column 1 and p-value in column 2 into <OMARU_project_dir>/data. Define the set of significantly enriched pathways in each result independently at the P<0.05 threshold (PQ parameter), then build a 2x2 contingency table of pathway counts (MWAS-significant vs GWAS-significant) per phenotype. Compute Fisher's exact test P-values (PFisher) with scipy.stats.fisher_exact on each table; rationale is that a significant overlap indicates shared disease biology between host germline pathways and the gut metagenome. Optionally run the integrated step 'snakemake -s Snakefiles/OMARU_Func_MWAS_GWAS.sm', which writes overlap tables and figures to <OMARU_project_dir>/result/FUNC_QCed3/MWAS_GWAS/<Pathway_reference>. Validate that the computed PFisher values reproduce 0.011 (SCZ) and 0.008 (T2D) within rounding tolerance.

## Related tools

- **OMARU** (End-to-end pipeline that produced the MWAS pathway enrichment results and provides the integrated MWAS-GWAS pathway interaction Snakemake workflow) — https://github.com/toshi-kishikawa/OMARU
- **PASCAL** (Used to derive pathway-level enrichment from host GWAS summary statistics (SCZ and T2D) that form one side of the contingency table)
- **Snakemake** (Workflow engine executing Snakefiles/OMARU_Func_MWAS_GWAS.sm which writes the overlap tables and figures)

## Examples

```
snakemake -s Snakefiles/OMARU_Func_MWAS_GWAS.sm
```

## Evaluation signals

- Computed PFisher equals 0.011 for SCZ and 0.008 for T2D within rounding tolerance
- Contingency tables are valid 2x2 pathway count tables built from independently thresholded (P<0.05) MWAS and GWAS significance sets
- Overlap call reproduces when the integrated snakemake step writes tables/figures to result/FUNC_QCed3/MWAS_GWAS/<Pathway_reference>
- MWAS side derives from sumstats_*_annot.txt outputs of OMARU_Func_permutation.sm, not raw association output
- Both phenotypes (SCZ, T2D) yield significant overlaps at P<0.05, consistent with the reported disease-specific metagenome–genome links

## Limitations

- OMARU does not currently integrate covariates into the case-control model (hidden confounding adjustment via covariate integration is not implemented), which can affect the upstream enrichment calls feeding this test
- Pathway overlap analysis is highly dependent on the reference databases used (e.g. KEGG/GO pathway references); no specific versions of tools or reference databases are stated in the article
- Significance threshold of P<0.05 is uncorrected for the overlap test itself; results depend on the pathway reference chosen
