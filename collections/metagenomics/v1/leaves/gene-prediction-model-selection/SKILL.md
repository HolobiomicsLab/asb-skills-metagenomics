# gene-prediction-model-selection

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Selects near-optimal gene prediction model parameters for each human-microbiome metagenomic contig by matching its initially predicted genes against a species-level pan-genome database, falling back to MetaGeneMark or GeneMarkS-2 when no pan-genome match is found. This replaces crude GC-content-only models with species-specific GeneMark.hmm-2 parameters.

## When to use

Use when annotating assembled human microbiome metagenome contigs and you must choose gene prediction parameters per contig, assigning contigs to species-level pan-genomes or routing unmatched contigs to fallback algorithms.

## When NOT to use

- The input is a complete prokaryotic genome suitable for self-training — use GeneMarkS-2 directly rather than pan-genome model selection.
- The metagenome is not from the human microbiome and its taxa are unlikely to be represented in the human-microbiome pan-genome database, so most contigs would fall back to MetaGeneMark/GeneMarkS-2 anyway.

## Inputs

- Assembled metagenome contigs in FASTA format (e.g. human gut, oral, or skin assembly)
- Pan-genome sequence database (pan.fasta, ~20 Gb) indexed as a BLAST nucleotide database via makeblastdb
- Database of pre-computed model files (refmod.tar) generated by GeneMarkS-2 for >5000 taxa
- NCBI blastn executable on PATH (or set via 'my $blastn' in gm_hm.pl)

## Outputs

- Final gene predictions in GTF format (output.gtf) with per-contig model provenance (pan-genome model, GeneMarkS-2, or MetaGeneMark)
- Per-contig pan-genome assignment decisions (majority-vote over matched genes)
- Optional translated (--aa aa.fasta) and nucleotide (--nt nt.fasta) gene sequences

## How to apply

First run initial gene predictions on each contig with MetaGeneMark (short/anonymous contigs) or GeneMarkS-2-class models, then use those predicted genes as blastn queries against the ~20 Gb pan-genome BLAST database built with 'makeblastdb -in pan.fasta -parse_seqids -dbtype nucl -out pan'. Retain hits with E-value <1e-5, at least 90 nt of aligned query sequence, and average nucleotide identity >95%; assign each contig to the pan-genome holding the majority of its matched genes. A confirmed assignment triggers selection of the corresponding pre-computed species/taxa-specific model from the refmod model library for GeneMark.hmm-2 (GeneMark.hmm-2), plus automatic selection of a translation start site sequence model. Contigs not matched to pan-genomes are processed by MetaGeneMark (shorter contigs) or GeneMarkS-2 (longer contigs), selected by contig length. The rationale is that species-specific parameters usually outperform general metagenomic parameters, and complete genomes of many human-associated taxa allow accurate parameters to be pre-estimated by GeneMarkS-2.

## Evaluation signals

- Check blastn hits were filtered to E-value <1e-5, alignment length >90 nt, and ANI >95% before pan-genome assignment.
- Compare the fraction of contigs routed through the pan-genome path against reported values: up to 99.4% for human gut, 89.0% oral, 79.4% skin metagenomes (Table 6).
- Run the bundled test ('bin/gm_hm.pl --seq ../sequence.fasta --cores 4 --out output.gtf --clean') and compare output.gtf against reference genemark.gtf with 'compp -a ../genemark.gtf -b output.gtf' for low false positives and high sensitivity.
- Verify that the majority-vote rule assigned each contig to the pan-genome holding the majority of its matched genes.
- Confirm unmatched contigs were split by length: MetaGeneMark for shorter, GeneMarkS-2 for longer.

## Limitations

- Accuracy depends on correct assignment of a contig to a reference pan-genome; misassignment degrades predictions.
- Oral and skin metagenomes have substantially lower pan-genome assignment coverage (89.0% and 79.4%) possibly because these microbiomes are mixed with environmental microbes.
- The length threshold distinguishing 'shorter' vs 'longer' unmatched contigs is not stated in the discussion text (deferred to Figure 1).
- No version numbers are stated for GeneMark-HM, GeneMark.hmm-2, GeneMarkS-2, MetaGeneMark, or MetaProdigal.
