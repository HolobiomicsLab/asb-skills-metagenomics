# kruskal-wallis-lda-effect-size-testing

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

LEfSe-style differential abundance testing applied to DeepMicrobes-derived UMGS species abundance profiles from the 106 iHMP IBD gut metagenomes, identifying uncultured metagenomic species biomarkers such as UMGS368 depleted in Crohn's disease and ulcerative colitis.

## When to use

Use when you have per-subject species/UMGS abundance profiles from metagenomic classification and need to detect taxa differentially abundant across disease groups (e.g. CD, UC, healthy) with an effect-size cutoff.

## When NOT to use

- Input is raw sequencing reads rather than aggregated per-subject abundance profiles — classification/prediction must be run first
- Comparing only two groups with a different test design, or requiring calibrated p-value correction rather than LEfSe-style LDA effect-size ranking
- Classifying reads against cultivated reference genomes where a standard taxonomic classifier suffices — this skill targets uncultured MGS biomarker discovery

## Inputs

- Per-subject UMGS/species abundance profiles generated with DeepMicrobes from 106 iHMP gut metagenome TFRecord predictions
- Sample-to-group metadata mapping subjects to CD, UC, and healthy categories

## Outputs

- lefse_umgs_biomarkers.tsv: UMGS passing Kruskal-Wallis significance with LDA effect size >2.0, including UMGS368 depleted in CD/UC
- Per-UMGS Kruskal-Wallis p-values and LDA effect-size scores

## How to apply

Take the per-subject UMGS abundance profiles generated by DeepMicrobes' profile-generation step from the 106 iHMP (PRJNA398089) gut metagenomes and group subjects into Crohn's disease, ulcerative colitis, and healthy categories. In R, run a Kruskal-Wallis test of each UMGS abundance across the three groups, then estimate LDA effect size (LEfSe-style) for taxa passing the significance test. Retain only biomarkers with LDA effect size >2.0. Compile the significant UMGS list (e.g. UMGS368, whose abundance decreases in both CD and UC) into a table such as lefse_umgs_biomarkers.tsv and cross-check against the paper's Figure 5 / Supplementary Table S14 biomarker set.

## Related tools

- **DeepMicrobes** (Produces the species/UMGS abundance profiles from iHMP metagenomes that feed the Kruskal-Wallis/LDA analysis) — https://github.com/MicrobeLab/DeepMicrobes
- **R** (Environment for running the Kruskal-Wallis tests and LDA effect-size (LEfSe-style) biomarker analysis) — https://github.com/MicrobeLab/DeepMicrobes-data/tree/master/scripts

## Examples

```
kw <- kruskal.test(abundance ~ diagnosis, data = umgs_profiles)
```

## Evaluation signals

- lefse_umgs_biomarkers.tsv contains only UMGS passing Kruskal-Wallis significance with LDA effect size >2.0
- Output biomarker calls reproduce the Figure 5 / Supplementary Table S14 biomarker set
- UMGS368 is called as significantly depleted in both Crohn's disease and ulcerative colitis
- Every retained biomarker has a tested abundance profile across all three groups (CD, UC, healthy) with no dropped subjects
- No biomarker with effect size ≤2.0 appears in the final table

## Limitations

- Signatures from the IBD reanalysis are described as potential; some corroborate previous genus-level findings while others are novel, so biomarker status needs external corroboration
- The analysis depends on DeepMicrobes species-call quality, which requires choosing an appropriate confidence threshold; adding new species to the classifier requires retraining the entire DNN
- Only uncultured MGS in the 2,505-species gut repertoire used for DeepMicrobes training can be detected; species outside it will not be classified
