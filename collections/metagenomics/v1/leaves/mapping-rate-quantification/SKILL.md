# mapping-rate-quantification

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

A cross-mapping contamination check that simulates paired-end Illumina reads covering a large marker-gene database (e.g. the 1.69 million FunOMIC-T fungal single-copy marker genes), aligns them to a reference catalog (UHGG, 204,938 non-redundant gut prokaryote genomes) with bowtie2, applies a strict samtools mapping filter, and reports the fraction of reads mapping — here validating that <0.01% of fungal markers cross-map to bacteria.

## When to use

Use when you must quantify how much of a newly built sequence database cross-maps to an independent reference catalog (e.g. checking a fungal marker database for bacterial contamination), or when computing a defensible mapping-rate summary for a large sequence set.

## When NOT to use

- You need genuine biological read alignment rather than a contamination/specificity bound — this skill quantifies cross-mapping of simulated reads, not real sample profiling
- The database is small enough to align query sequences directly without read simulation — ART simulation exists specifically to work around memory limits on 1.69 M sequences
- You are doing functional protein annotation — that uses Diamond blastx with coverage >95%, identity >99%, e-value <10e-10 thresholds, not this read-mapping rate check

## Inputs

- FunOMIC-T fungal single-copy marker gene sequences (1.69 million, FASTA)
- UHGG reference catalog (204,938 non-redundant genomes from 4,644 gut prokaryotes, indexed for bowtie2)
- Simulated paired-end Illumina FASTQ reads generated by ART (22 million pairs, 1-fold coverage)

## Outputs

- Filtered SAM/BAM of high-confidence mapped reads (>80% aligned length, q-score >30)
- Mapping-rate summary table (fraction of marker-gene reads mapping to UHGG)
- Mapping-rate figure supporting the <0.01% contamination bound

## How to apply

First obtain the query sequences (1.69 million FunOMIC-T fungal single-copy marker genes) and the reference catalog (UHGG). Because aligning 1.69 M sequences directly exceeds practical memory, simulate paired-end Illumina reads covering all sequences with ART (e.g. 22 million paired reads at 1-fold coverage, ~11.2 GB RAM). Align the simulated reads to the reference with bowtie2, then filter with Samtools v1.9 keeping only mapped reads where more than 80% of the read length aligns with a q-score over 30 — this strict threshold keeps only high-confidence cross-mappings. Compute the fraction of marker-gene reads mapping to the reference and write a mapping-rate summary table and figure; the acceptance criterion in this study is <0.01% of fungal marker gene reads mapping to UHGG.

## Related tools

- **ART** (Simulates synthetic paired-end Illumina reads covering all 1.69 million marker genes (22M paired reads, 1-fold coverage) to sidestep memory limits of direct sequence alignment)
- **bowtie2** (Aligns the simulated marker-gene reads to the UHGG reference catalog) — http://bowtie-bio.sourceforge.net/bowtie2/index.shtml
- **Samtools** (v1.9 — filters alignments, keeping mapped reads with >80% aligned length and q-score >30 before rate computation) — http://www.htslib.org/

## Examples

```
bowtie2 -x UHGG_index -1 markersim_R1.fq -2 markersim_R2.fq | samtools view -q 30 -b - > filtered_mapped.bam
```

## Evaluation signals

- Mapping rate of marker-gene reads against UHGG is below the acceptance threshold of 0.01%, matching the published result
- Only reads with >80% of their length aligned and q-score >30 are counted; verify the samtools filter is applied before rate computation
- Simulated read set covers all marker gene sequences (22 million paired reads at 1-fold coverage, ~11.2 GB) — spot-check coverage of input FASTA
- A mapping-rate summary table and figure are produced and the denominator (total simulated marker-gene reads) is reported
- Symmetry check: the reciprocal test (bacterial mock of 903 genomes / 458 species against FunOMIC-T) also yields <0.01% mapping, consistent with specificity 0.9999

## Limitations

- Direct alignment of the full 1.69 million marker genes against UHGG is memory-prohibitive; read simulation (ART) is a workaround that approximates rather than exhaustively aligns each sequence
- High inter-kingdom conservation of protein-coding genes means residual bacterial cross-mapping was not totally preventable even with strict thresholds
- Results depend on marker gene quality, which in turn relies on the completeness of available fungal genomes
