# metagenome-assembled-genome-quality-assessment

## Summary

Quality-control step of the nf-core/mag pipeline that reconstructs MAG QC metrics: QUAST summarizes assembly features (contig count, total length, N50) of each binned contig set, while BUSCO estimates completeness and contamination from near-universal single-copy orthologs.

## When to use

Use when binned contig FASTA files (MAG bins) have been produced by a binning step and per-bin completeness, contamination, and assembly statistics (N50, contig count, total length) must be estimated and summarized.

## When NOT to use

- Input is raw reads or unbinned assemblies — this skill operates on binned contig sets (MAGs), not on FASTQ or single (co-)assemblies without bins
- A bin refinement step is needed rather than QC — the article explicitly notes a 'Bin refinement step not yet included' in nf-core/mag 2.1.0, and QUAST/BUSCO do not merge or optimize bins
- Functional or taxonomic annotation of MAGs is the goal rather than completeness/contamination estimation

## Inputs

- Binned contig FASTA files (one or more per MAG) from the genome binning step
- Optionally, assembly FASTA files of the underlying assemblies

## Outputs

- Per-bin QUAST assembly statistics (contig count, total length, N50)
- Per-bin BUSCO completeness and contamination estimates
- Aggregated per-bin summary table (bin name, completeness, contamination), e.g. a mag_qc_summary.tsv
- MultiQC report aggregating QC metrics

## How to apply

Load the binned contig FASTA files produced for each MAG. Run QUAST on every binned contig set to compute per-bin assembly statistics (contig count, total length, N50). Run BUSCO on each bin in automated lineage selection mode so the best-matching lineage database is chosen; BUSCO estimates completeness and contamination using near-universal single-copy orthologs. Aggregate QUAST and BUSCO metrics into a single per-bin summary table (bin name, completeness, contamination), which in nf-core/mag is surfaced through MultiQC and can feed downstream dashboards such as BIgMAG.

## Related tools

- **QUAST** (Summarizes QC features (contig count, total length, N50) of generated assemblies and MAGs)
- **BUSCO** (Estimates MAG completeness and contamination using near-universal single-copy orthologs in automated lineage selection mode)
- **nf-core/mag** (Pipeline that orchestrates the bin QC step and aggregates the QC metrics) — https://github.com/nf-core/mag
- **MultiQC** (Aggregates QUAST and BUSCO QC outputs into a single report)
- **BIgMAG** (Downstream dashboard displaying multiple metagenome quality metrics from the file generated by nf-core/mag) — jeffe107/BIgMAG
- **CheckM2** (Alternative/complementary tool for predicting bin completeness and contamination via machine learning) — chklovski/CheckM2

## Examples

```
busco -i bin1.fa -m auto -o busco_bin1 && quast.py bin1.fa -o quast_bin1
```

## Evaluation signals

- mag_qc_summary.tsv exists and contains exactly one row per input bin
- Completeness and contamination fields are present (non-empty) for every bin in the summary table
- BUSCO runs completed in automated lineage selection mode with a best-matching lineage database reported per bin
- QUAST output per bin includes contig count, total length, and N50 statistics
- MultiQC report successfully ingests both the QUAST and BUSCO results

## Limitations

- Bin refinement is not part of this QC step; the article notes nf-core/mag 2.1.0 still lacks a 'Bin refinement step'
- BUSCO lineage choice depends on automated lineage selection; quality estimates are lineage-dependent and less reliable for lineages with few high-quality representatives (as CheckM2 notes for CheckM1-style approaches)
- Functional annotation was also 'not yet included' in the pipeline version described, so QC metrics alone do not annotate MAG function
