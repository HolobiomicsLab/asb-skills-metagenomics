# metagenome-dataset-retrieval-sra

## Summary

Retrieves the three simulated benchmark metagenomes used by the Kraken paper — the HiSeq and MiSeq metagenomes by accession from the NCBI Sequence Read Archive, and the simBA-5 metagenome generated with the Mason read simulator — so that downstream classification speed and accuracy benchmarks start from the paper's exact read sets.

## When to use

Use when a reproduction task requires the HiSeq, MiSeq or simBA-5 metagenomes referenced by NCBI SRA accessions (SRS019120, SRS014468, SRS015055) as classification-benchmark input.

## When NOT to use

- The benchmark read sets are already available locally as trimmed FASTA/FASTQ files — re-download or re-simulate would waste effort and risk version drift.
- The analysis target is classifying reads with Kraken/Megablast/MetaPhlAn rather than obtaining the input metagenomes (use the classification/benchmarking skills instead).
- A different metagenome (e.g. the simMC low/medium complexity set or a real environmental sample) is required — this skill only covers the HiSeq, MiSeq and simBA-5 benchmark sets.

## Inputs

- NCBI SRA accessions SRS019120, SRS014468 and SRS015055 (HiSeq and MiSeq metagenomes)
- Complete bacterial and archaeal genomes from NCBI RefSeq (source for simBA-5 simulation)
- Mason read simulator Illumina model parameters (default mismatch/indel rates multiplied by five)

## Outputs

- HiSeq metagenome read set (FASTA/FASTQ)
- MiSeq metagenome read set (FASTA/FASTQ)
- simBA-5 metagenome read set generated by Mason with 2% average mismatch rate

## How to apply

First retrieve the HiSeq and MiSeq metagenomes by their NCBI Sequence Read Archive accessions (SRS019120, SRS014468, SRS015055). For the third metagenome, do not download — generate simBA-5 by simulating reads with the Mason read simulator using its Illumina model from complete bacterial and archaeal genomes in RefSeq, multiplying Mason's default mismatch and indel rates by five so the average mismatch rate reaches 2%. Trim all retrieved/simulated sequences to remove low quality bases and adapter sequences before any classifier sees them, since the paper's benchmark read sets were prepared this way. Keep the three metagenomes separated as distinct benchmark inputs (each corresponds to a distinct throughput/accuracy measurement), and record provenance (accession vs. Mason simulation parameters) for each.

## Related tools

- **Mason** (Read simulator used to generate the simBA-5 metagenome from RefSeq bacterial and archaeal genomes using its Illumina model with mismatch and indel rates multiplied by five)
- **NCBI Sequence Read Archive** (Source repository from which the HiSeq and MiSeq metagenome read sets are downloaded by accession)

## Evaluation signals

- The three metagenomes map to the correct provenance: two downloaded by SRA accessions (SRS019120, SRS014468, SRS015055) and one generated by Mason simulation.
- simBA-5 simulation settings reproduce the paper's protocol: Mason Illumina model with default mismatch and indel rates multiplied by five, yielding an average mismatch rate of 2%.
- Each retrieved/simulated metagenome contains sequences from ten genomes, as in the paper's benchmark sets.
- All sequences have been trimmed to remove low quality bases and adapter sequences before being passed to a classifier.
- Downstream speed benchmarks can be re-run directly: Kraken throughput should exceed 1.5M rpm (HiSeq), 1.3M rpm (simBA-5) and 890K rpm (MiSeq) on these inputs.

## Limitations

- The article does not specify the Mason read simulator version or the exact SRA download command, so bit-level reproduction depends on tool versions at retrieval time.
- simBA-5 must be generated, not downloaded — it exists only as a simulation recipe (RefSeq genomes + Mason with 5× mismatch/indel rates), so reproducibility depends on which RefSeq genomes were in the database.
- Sequences from the ten-genome composition of each metagenome are described in Additional file 1 (Tables S1 and S2), whose content is not included in the article text.
