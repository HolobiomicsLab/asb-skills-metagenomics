# metagenomic-contamination-assessment

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Quantifies cross-mapping contamination between a taxonomic marker database and an unrelated reference catalog (here, 1.69 million FunOMIC-T fungal single-copy marker genes vs. the UHGG catalog of 204,938 gut prokaryote genomes) by simulating reads and aligning them with bowtie2 under a strict Samtools filter, accepting <0.01% cross-mapping as database specificity.

## When to use

Use when validating that a custom marker-gene or reference database is specific to its target kingdom by measuring how many of its sequences align against a large out-group reference catalog (e.g., fungal markers vs. a bacterial gut genome catalog).

## When NOT to use

- Input is already mapped data or a feature table — this skill assesses database contamination at the sequence level, not sample-level contamination
- The reference catalog is from the same kingdom as the marker genes (e.g., fungal vs. fungal), where cross-mapping is expected and the <0.01% specificity bound does not apply
- Evaluating functional annotation contamination, which requires different thresholds (Diamond blastx: read coverage >95%, identity >99%, e-value <10e-10)

## Inputs

- Fungal single-copy marker gene sequences (1.69 million FunOMIC-T marker genes, FASTA)
- UHGG reference catalog (204,938 non-redundant genomes from 4,644 gut prokaryotes)
- Simulated paired-end Illumina reads (~22 million pairs, 1-fold coverage) generated by ART

## Outputs

- Mapping-rate summary table (fraction of marker-gene reads mapped to the reference catalog)
- Mapping-rate figure
- Contamination bound estimate (<0.01% acceptance threshold)

## How to apply

Obtain the marker-gene set (e.g., the 1.69 million FunOMIC-T fungal single-copy marker genes) and the reference catalog (UHGG, 204,938 non-redundant genomes from 4,644 gut prokaryotes). When the full sequence set exceeds memory limits, use ART to simulate paired-end Illumina reads covering all marker sequences at ~1-fold coverage (~22 million read pairs, ~11.2 GB). Align the simulated reads to the reference with bowtie2, then filter mapped alignments with Samtools v1.9, keeping only reads where more than 80% of the read length aligned with a MAPQ over 30. Compute the fraction of marker-gene reads mapping to the reference; the acceptance criterion in the paper is that fewer than 0.01% of fungal marker-gene reads map to UHGG, demonstrating the database is specific enough to detect mostly fungal sequences.

## Related tools

- **ART** (Simulates paired-end Illumina reads covering all marker gene sequences (22 million pairs, 1-fold coverage) to work around memory limits of aligning full sequences)
- **bowtie2** (Aligns the simulated fungal marker-gene reads against the UHGG reference catalog) — http://bowtie-bio.sourceforge.net/bowtie2/index.shtml
- **Samtools** (Filters mapped alignments (v1.9), keeping reads with >80% of read length aligned and q-score over 30) — http://www.htslib.org/
- **FunOMIC** (Source pipeline whose FunOMIC-T database (1.69 million fungal single-copy marker genes) is the sequence set being assessed for contamination) — https://github.com/ManichanhLab/FunOMIC

## Examples

```
bowtie2 -x uhgg_index -1 sim_R1.fastq -2 sim_R2.fastq | samtools view -bS - | samtools view -b -q 30 -F 4 > mapped_filtered.bam
```

## Evaluation signals

- Fewer than 0.01% of the fungal marker-gene reads map to UHGG (paper acceptance criterion)
- Filtered BAM contains only reads where more than 80% of read length aligned with MAPQ > 30
- Simulated read set covers all marker gene sequences at ~1-fold coverage (~22 million paired reads, ~11.2 GB)
- Mapping-rate summary table and figure reproduce the reported contamination bound
- Symmetric check: bacterial mock community (903 genomes, 458 species) shows <0.01% mapping rate against FunOMIC-T, confirming bidirectional specificity

## Limitations

- Full sequence alignment of 1.69 million marker genes is memory-intensive; read simulation with ART is a workaround that may not capture all alignment behaviors of full-length sequences
- High inter-kingdom conservation of protein-coding genes means bacterial contamination was not totally preventable, even with strict mapping thresholds
- Marker gene extraction and quality depend on completeness of available fungal genomes, which can limit taxonomy coverage
