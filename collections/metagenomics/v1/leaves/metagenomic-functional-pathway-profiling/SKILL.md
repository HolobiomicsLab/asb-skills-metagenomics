# metagenomic-functional-pathway-profiling

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Constructs metagenomic functional pathway profiles and tests case-control pathway enrichment with OMARU, then links disease-enriched pathways to host GWAS pathway enrichments via Fisher's exact test (PFisher = 0.011 SCZ, 0.008 T2D), revealing disease-specific metagenome-genome connections.

## When to use

Use when shotgun metagenomic case-control data (e.g. SCZ n=344, T2D n=171) require pathway-level enrichment testing and integration with host GWAS summary statistics to evaluate pathway overlap.

## When NOT to use

- Input is raw FASTQ or already-existing gene abundance tables rather than completed pathway enrichment results — run the OMARU functional profiling steps first
- No host GWAS summary statistics are available, so the metagenome-genome overlap test cannot be constructed
- The analysis targets phylogenetic (clade/taxon) associations rather than biological pathway enrichment

## Inputs

- MWAS pathway enrichment results: sumstats_*_annot.txt from Snakefiles/OMARU_Func_permutation.sm (SCZ n=344, T2D n=171 cohorts)
- Host GWAS pathway enrichment files formatted as <Phenotype>_GWAS_<Pathway_reference>.txt (column 1: pathway ID, column 2: p-value) generated by PASCAL from GWAS summary statistics
- KEGG pathway reference database for gene and biological pathway annotation

## Outputs

- 2x2 contingency tables of pathway counts (MWAS-significant vs GWAS-significant) per phenotype
- Fisher's exact test P-values (PFisher = 0.011 SCZ, 0.008 T2D) saved to MWAS_GWAS_pathway_overlap_PFisher.tsv
- Tables and figures of MWAS-GWAS pathway links in <OMARU_project_dir>/result/FUNC_QCed3/MWAS_GWAS/<Pathway_reference>

## How to apply

Run OMARU's functional association module (Snakefiles/OMARU_Func_AS.sm then OMARU_Func_permutation.sm) on QCed metagenomes, using KEGG as the gene/pathway reference and adjusting for covariates (sex, age, BMI, top 30 PCs) to suppress P-value inflation, yielding sumstats_*_annot.txt files. Independently run PASCAL on host GWAS summary statistics (SCZ: 22,778 cases/35,362 controls; T2D: 77,418 cases/433,544 controls) and format results as <Phenotype>_GWAS_<Pathway_reference>.txt (pathway ID, p-value) in <OMARU_project_dir>/data. Define pathways significant at P<0.05 in both MWAS and GWAS, build the 2x2 contingency table of pathway counts per phenotype, and compute Fisher's exact test P-values with scipy.stats.fisher_exact. Alternatively execute the integrated step 'snakemake -s Snakefiles/OMARU_Func_MWAS_GWAS.sm', which writes overlap tables and figures to <OMARU_project_dir>/result/FUNC_QCed3/MWAS_GWAS/<Pathway_reference>. Significant overlaps indicate disease-specific links between the human genome and metagenome.


## Evaluation signals

- Computed PFisher values equal the reported 0.011 (SCZ) and 0.008 (T2D) within rounding tolerance
- Overlap significance uses the specified threshold P<0.05 for both MWAS and GWAS pathway lists
- Contingency tables contain only pathways counted once per phenotype with consistent pathway IDs across MWAS and GWAS references
- Output files MWAS_GWAS_pathway_overlap_PFisher.tsv and result/FUNC_QCed3/MWAS_GWAS/<Pathway_reference> tables/figures are produced without error
- MWAS P-value inflation is suppressed by covariate adjustment (sex, age, BMI, top 30 PCs) before significance calling

## Limitations

- Results depend on the pathway reference database chosen (KEGG in the published example); OMARU analysis is highly dependent on reference databases
- The overlap test requires pre-computed GWAS pathway enrichments (PASCAL output), not raw GWAS summary statistics
- Significance is called at nominal P<0.05 per pathway, not at a multiple-testing-corrected level in the overlap step
