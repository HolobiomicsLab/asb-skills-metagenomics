# metagenomic-shotgun-read-simulation

## Summary

Constructs in silico shotgun metagenomic benchmark datasets with known strain composition and prescribed sequencing depths (3x-35.5x over 100 samples in three groups) by mutating reference Fusobacterium genomes with BBMap and simulating 151 bp paired-end NovaSeq reads with InSilicoSeq, enabling controlled evaluation of strain-level variant callers such as MetaQuad.

## When to use

Use when benchmarking strain-level metagenomic variant discovery tools (e.g., MetaQuad, MQuad) and you need simulated shotgun communities with known ground-truth strain mixtures, engineered variants, and per-sample mean depths spanning 3x-35.5x.

## When NOT to use

- You need to discover or genotype variants in real patient metagenomes rather than generate controlled benchmark data (use MetaQuad/cellsnp-lite directly on real reads instead)
- The target platform is not 151 bp paired-end shotgun sequencing on a NovaSeq-like instrument, since the simulation is parameterized with the --model novaseq error model
- Ground-truth strain composition is already available from real samples, making simulation unnecessary for the benchmark

## Inputs

- Reference genome FASTA files (five Fusobacterium genomes downloaded from NCBI)
- Substitution rates for the four engineered strain variants
- Per-sample mean depth targets spanning 3x-35.5x and group assignments (three groups, 100 samples total)
- Read length (151 bp per mate) and error model choice (NovaSeq)

## Outputs

- Four mutated strain FASTA files generated by BBMap mutate.sh
- 100 gzipped paired-end FASTQ sample pairs with prescribed depths and strain composition
- Ground-truth mapping of each sample to its assigned strains and engineered variant sites

## How to apply

Download the reference genomes (five Fusobacterium genomes from NCBI) and concatenate them into a single multi-species FASTA to serve as the simulation template. Run BBMap mutate.sh four times on the combined reference at specified substitution rates to produce four strain-derived FASTA variants, then assign the five reference species and four mutated strains across 100 samples organized into three groups with defined strain-composition percentages. For each sample, run InSilicoSeq ('iss generate') with the NovaSeq error model (--model novaseq) to generate 151 bp paired-end reads, setting the per-sample read count as depth x reference size / (2 x read length) so the mean depth lands on prescribed values from 3x to 35.5x. The realized ground truth (which strain each read set derives from and where the engineered variant sites sit) then supports downstream benchmarking with cellsnp-lite pileup and MetaQuad variant calling.

## Related tools

- **InSilicoSeq** (Simulates the paired-end 151 bp shotgun reads with the NovaSeq (--model novaseq) error model at per-sample depths of 3x-35.5x via 'iss generate')
- **BBMap** (mutate.sh generates the four strain-derived genome variants from the combined Fusobacterium reference at specified substitution rates)
- **Python** (Used for the simulation orchestration and per-sample read-count computation (depth x reference size / (2 x read length)))
- **MetaQuad** (Downstream shared-variant detector whose performance the simulated datasets are built to evaluate) — https://github.com/holab-hku/MetaQuad

## Examples

```
iss generate --genomes sample_strains.fasta --model novaseq --n_reads 1000000 --cpus 8
```

## Evaluation signals

- Exactly 100 gzipped paired-end FASTQ sample pairs are produced (200 FASTQ files total)
- Each sample's reads align to its assigned strain reference and carry the expected per-strain variant sites from the mutate.sh substitution rates
- Realized mean sequencing depths across the three groups span the prescribed 3x-35.5x range
- Per-sample read counts match the formula depth x reference size / (2 x 151 bp)
- Group-level strain composition matches the defined percentages for Groups 1, 2, and 3

## Limitations

- Simulation is limited to a single genus template (five Fusobacterium genomes plus four substitution-derived strains), so community diversity and phylogenetic breadth are constrained
- Reads are 151 bp paired-end with the NovaSeq error model only; other read lengths or instrument error profiles are not covered by this configuration
- Engineered diversity comes from substitution-rate mutations (BBMap mutate.sh), which may not capture indels, structural variation, or real evolutionary divergence between strains
- Depths are prescribed over a finite range (3x-35.5x), so very low- or very high-depth regimes are not represented
