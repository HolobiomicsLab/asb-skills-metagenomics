# microbial-phenotypic-character-prediction

## Summary

Train and apply 42 per-character LibSVM sentence classifiers (the MicroPIE Character Predictor) to assign sentences from prokaryotic taxonomic descriptions to one of 42 microbial phenotypic characters before rule-based character-state extraction. The SVM component filters out sentences unlikely to describe a character, which notably improves extraction precision.

## When to use

Use when sentences from natural-language microbial taxonomic descriptions must be assigned to phenotypic characters (e.g., Gram stain, motility, NaCl optimum) prior to rule-based character-state extraction, or when reproducing MicroPIE's reported SVM cross-validation metrics.

## When NOT to use

- The input text is not natural-language taxonomic description sentences but already structured data (e.g., a filled taxon-by-character matrix) — no character prediction is needed.
- A domain-independent extraction setting without labelled training sentences is required; the paper shows OIE/DeepDive alternatives were inadequate, and MicroPIE's SVM requires the labelled 17,147-instance corpus and domain Term Lists.
- The target characters are outside MicroPIE's scope (0.1.0 supports 42 characters; characters like antibiotic production or biofilm formation require version 0.2.0).

## Inputs

- Labelled sentence training corpus (17,147 instances, 42 phenotypic characters) from MicroPIE 'models' package resources
- Term Lists of characters from models/CharacterValueExtractors0.1.0
- Prokaryotic taxonomic descriptions in plain text (e.g., folder F:/MicroPIE/datasets/Part_One_111_final)

## Outputs

- Trained per-character SVM models stored under models/character_model0.1.0
- Per-character and summary cross-validation metrics (cv_metrics.csv with precision/recall per fold)
- Sentence-level character predictions feeding the taxon-by-character matrix generated by MicroPIE

## How to apply

Load the labelled sentence training corpus of 17,147 instances covering 42 microbial phenotypic characters from the MicroPIE 'models' package resources, and configure one LibSVM classifier per character using the Term Lists under models/CharacterValueExtractors0.1.0. Train each classifier on its labelled sentence instances, then run 10-fold cross validation and record per-fold precision and recall for character prediction. Accept the reproduction when average precision is approximately 98.6% and average recall is approximately 99.5%, matching the reported values. In deployment, the trained models stored under models/character_model0.1.0 assign each input sentence to a character (or none), and only character-bearing sentences are passed downstream to the linguistic rule-based extractors — this is the design choice that improves MicroPIE's overall precision.

## Related tools

- **MicroPIE 0.1.0** (Application housing the Character Predictor: packages the labelled sentence corpus, Term Lists, and the 42 trained LibSVM models; invoked via its Main class or micropie-0.1.0.jar with -i/-o/-m parameters.) — github.com/biosemantics/micropie2
- **SVM (Support Vector Machine)** (Supervised classification algorithm used to build one LibSVM classifier per character to identify which of the 42 characters a sentence describes.) — github.com/biosemantics/micropie2

## Examples

```
Java –cp micropieproject_lib –jar micropie-0.1.0.jar -i F:/MicroPIE/datasets/Part_One_111_final -o F:/MicroPIE/ext/craft -m F:/MicroPIE/MicroPIEWEB/models
```

## Evaluation signals

- 10-fold cross-validation average precision across the 42 classifiers is approximately 98.6%.
- 10-fold cross-validation average recall across the 42 classifiers is approximately 99.5%.
- cv_metrics.csv contains per-fold precision and recall for each of the 42 classifiers plus cross-classifier averages.
- Trained model files are present under models/character_model0.1.0 and match the 42 characters enumerated in models/CharacterValueExtractors0.1.0 Term Lists.
- End-to-end, the MicroPIE system evaluated against the hand-generated gold standard matrix reaches Relaxed_F1 > 0.80 on 21 of 42 characters (50%) with the SVM component included.

## Limitations

- Character prediction improves overall performance, notably precision, but the downstream rule-based extraction still leaves nearly half of the designated characters with Relaxed_F1 scores not above 0.80.
- Further development, including incorporation of ontologies, is acknowledged as necessary to improve extraction performance for some character types; the authors expect future improvements to make the system more robust.
- The character set is fixed by the shipped Term Lists: MicroPIE 0.1.0 handles 42 characters, and additional characters (e.g., antibiotic production, biofilm formation) only appear in 0.2.0.
