# miner-prediction-overlap-analysis

## Summary

Compares which vOTUs each phage miner (DeepVirFinder, VirSorter2, VIBRANT, Phigaro) predicted in a MetaPhage run, building an upSet plot and per-miner count table that reveals consensus versus miner-specific calls on metagenomic assemblies.

## When to use

Use when a metagenomic (or virome) dataset has been mined by multiple phage-mining tools and you need to quantify per-miner prediction counts and overlap/difference in vOTU assignments across miners.

## When NOT to use

- You only have predictions from a single miner, so no cross-miner overlap can be computed
- Contigs have not yet been dereplicated into vOTUs (95% identity / 85% coverage), so miner outputs cannot be assigned to a shared unit
- The goal is viral quality assessment rather than miner agreement — CheckV is used in the paper to attribute vOTU count differences to partial/low-quality genome predictions

## Inputs

- Per-miner viral contig predictions (from DeepVirFinder, VirSorter2, VIBRANT, Phigaro) on assembled metagenomic contigs
- Dereplicated vOTU FASTA (CD-HIT-EST consensus viral scaffolds, >=3000 bp)
- Per-sample MEGAHIT assemblies of quality-controlled reads (fastp-trimmed, phiX-removed)
- MetaPhage project configuration file (project.conf generated by newProject.py)

## Outputs

- UpSet plot summarizing prediction overlap between the five miners
- vOTU count table partitioned by miner combinations (e.g., counts unique to DeepVirFinder+VIBRANT, or predicted by all miners)
- Per-miner prediction counts (e.g., DeepVirFinder: 10,508 predictions)

## How to apply

Run the MetaPhage pipeline so that quality-controlled reads from each sample are assembled per-sample with MEGAHIT and mined with all five miners (in MetaPhage v2 beta: DeepVirFinder replacing VirFinder, VirSorter2 replacing VirSorter, VIBRANT, and Phigaro). Dereplicate the consensus viral scaffolds with CD-HIT-EST using a sequence identity threshold of 0.95, word size 9, alignment coverage 0.85, and --minlen 3000 to define vOTUs of at least 3,000 bp. Then build the miner-comparison summary as an upSet plot plus a vOTU count table, which partitions vOTUs by the set of miners that predicted them. The rationale is that miners disagree substantially — e.g., on the Liang et al. 2020 infant shotgun stool dataset (59 samples), DeepVirFinder was highest with 10,508 predictions out of 14,274 total vOTUs, 24.8% of vOTUs were predicted only by DeepVirFinder and VIBRANT, and only 2.3% by all five miners — so cross-miner overlap exposes which calls are consensus versus miner-specific.

## Evaluation signals

- Total vOTU count after dereplication matches the reported expectation for the benchmark dataset (e.g., 14,274 vOTUs on the 59-sample Liang et al. 2020 shotgun dataset)
- Per-miner prediction counts are consistent with reported rankings (DeepVirFinder highest with 10,508 predictions)
- Overlap fractions reproduce the reported partition: 24.8% of vOTUs predicted only by DeepVirFinder and VIBRANT; 2.3% by all five miners
- All vOTUs in the comparison table are >=3000 bp (the --minlen 3000 filter was applied)
- The upSet plot's set sizes sum to the total dereplicated vOTU count

## Limitations

- Large differences in vOTU counts between miners largely reflect predictions of more partial and low-quality genomes (assessed with CheckV), not necessarily true extra viruses
- Miner composition changed in MetaPhage v2 beta (DeepVirFinder replacing VirFinder, VirSorter2 replacing VirSorter), so overlap statistics are not comparable across pipeline versions
- Users should be mindful of biases inherent to virome analyses affecting recall/precision of virus prediction
