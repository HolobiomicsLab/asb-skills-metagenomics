# minimum-p-value-statistic-testing

## Summary

Implements the adaptive multi-marker meta-analysis (aMeta) test statistic, formed as the minimum p-value across Q marker-specific random effects meta-analyses, with its null distribution generated by the Follmann–Proschan group permutation method without prior marker-by-marker correlations.

## When to use

Use when combining multiple studies across multiple related markers (e.g., 6 α-diversity indices) from summary statistics only (effect estimates and standard errors) and an omnibus hypothesis test is needed without a priori marker-by-marker correlations.

## When NOT to use

- When pooled effect estimates (not just hypothesis testing) across markers are needed — aMeta is limited to hypothesis testing; use mMeta instead
- When fewer than 10 studies per marker are available — the mMeta.aMeta function requires the number of studies to be ≥ 10
- When marker-by-marker correlations are already known and a multivariate method exploiting them directly is preferred

## Inputs

- A data.frame or matrix of study-specific effect estimates (e.g., regression coefficients); rows are studies, columns are markers; NAs allowed if matched between est and std.err; at least 10 studies
- A data.frame or matrix of study-specific standard errors with row/column names matching est
- Optional parameters: tau0 (default FALSE, Han and Eskin's modified random effects), n.perm (default 5000), seed

## Outputs

- Pooled estimates, 95% confidence intervals, and p-values for each marker (mMeta)
- A p-value across markers using aMeta (the minimum p-value statistic)
- CSV file (ameta_results.csv) of marker-specific pooled p-values and the overall aMeta p-value

## How to apply

Load study-by-marker effect estimates and standard errors (rows = studies, columns = markers, e.g., Sum.Data or HIV.Sum.Data with 15 HIV studies and 6 α-diversity indices), requiring at least K = 10 studies per marker. For each marker, run a single-marker random effects meta-analysis using the SJ heterogeneity variance estimator. Apply the Follmann and Proschan (1999) group permutation method — randomly assign ±1 signs to the absolute effect estimates (R = 5000 permutations by default, or all 2^K permutations when K < 15) and recompute null pooled effects with permuted heterogeneity estimates set to zero (Han and Eskin's modification, tau0=FALSE) — to derive marker-specific null p-values. Form the aMeta statistic T = min Pj across the Q markers and compute its p-value as the proportion of permutation-level minimum p-values at least as extreme as the observed minimum. Validate by reproducing the reference mMeta.aMeta(est, std.err, seed=123) output for the same example data.

## Evaluation signals

- Reimplemented marker-specific p-values match the mMeta.aMeta(seed=123) package output for the same example summary data
- The aMeta p-value matches the reference package output within permutation-seed reproducibility
- Each marker-specific meta-analysis used the SJ heterogeneity variance estimator with at least K = 10 studies per marker
- Permutation scheme matches the spec: R = 5000 by default, or all 2^K permutations when K < 15, with permuted heterogeneity estimates set to zero (tau0=FALSE)
- Output CSV contains both the marker-level pooled p-values and the overall aMeta p-value

## Limitations

- aMeta is limited to hypothesis testing — it does not provide pooled effect estimates across markers
- The mMeta.aMeta function requires at least 10 studies; with fewer than 15 studies, all possible permutations are implemented and n.perm and seed are ignored
- Effect estimates and their standard errors required by mMeta and aMeta are hard to obtain in practice, as many studies report only graphs or stratified summary statistics
- There are no set criteria for selecting candidate markers for mMeta and aMeta; selection rules should be explicitly delineated
- No version number is stated for the mMeta R package and no changelog is available for the repository
