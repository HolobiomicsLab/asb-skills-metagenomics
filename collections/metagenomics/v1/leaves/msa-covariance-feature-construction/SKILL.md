# msa-covariance-feature-construction

## Summary

Constructs covariance matrices from a protein multiple sequence alignment (MSA) as input features for a deep neural network that predicts residue contacts end-to-end, as in the DeepECA Baseline Model that outperformed existing ECA methods on CASP11 and CASP12.

## When to use

Use when predicting protein residue contacts directly from an MSA with a DNN, or when replicating the DeepECA Baseline Model precision benchmarks on CASP11/CASP12 against PSICOV, CCMpred, DeepCov, and ResPRE.

## When NOT to use

- Protein sequences are longer than 200 residues and uncropped full-length contacts are required, since sequences are cropped to 200 residues during training
- The task requires a precision-matrix-based method rather than a covariance-matrix input (e.g. replicating ResPRE)
- No homologous sequences are available, so HHblits cannot produce an MSA with sufficient evolutionary information

## Inputs

- Amino acid FASTA sequences of target proteins (placed in ./dataset/fasta)
- MSAs generated by HHblits (three iterations, E-value 0.001, 60% coverage, UniProt20_2016 library)
- CASP11 (105 domains) and CASP12 (55 domains) benchmark datasets with known structures
- Pre-trained models and training datasets from the DeepECA Google Drive folder

## Outputs

- Covariance matrices computed from MSAs (DNN input features, sequences cropped to 200 residues, up to 30,000 sequences sampled)
- Contact predictions stored in ./contact_pred
- Secondary structure predictions stored in ./ss_pred (multitask model)
- Precision values TP/(TP+FP) at top L/10, L/5, L/2, and L for short, medium, and long sequence-separation ranges

## How to apply

Generate MSAs for target proteins with HHblits using three iterations, E-value 0.001, and 60% coverage against the UniProt20_2016 library. Compute the covariance matrix from each MSA as the DNN input feature, cropping protein sequences to 200 residues and sampling 30,000 MSA sequences when the MSA is larger. Train the 60-layer residual network with multitask.py using the ADAM optimizer (learning rate 0.0005), batch normalization, and one domain per batch (about 2-3 days on an NVIDIA TITAN GTX GPU). Then run pipeline.py to predict contacts, storing results in ./contact_pred, and evaluate precision TP/(TP+FP) at top L/10, L/5, L/2, and L predictions for short-, medium-, and long-range contacts. Contacts are defined as Cβ atom pairs within 8 Å (Cα for glycine).

## Related tools

- **HHblits** (Generates the MSAs from which covariance-matrix input features are computed (three iterations, E-value 0.001, 60% coverage))
- **DeepECA** (Provides the residual-network code (multitask.py for training, pipeline.py for prediction) that consumes the covariance-matrix features) — https://github.com/tomiilab/DeepECA

## Examples

```
python pipeline.py  # after setting up hhblits in run_hhblits_local.py and downloading pre-trained models; training: python multitask.py
```

## Evaluation signals

- Computed Baseline precision at top L/10, L/5, L/2, and L matches the Baseline rows of Tables 11 and 12 for CASP11 (105 domains) and CASP12 (55 domains)
- Baseline precision outperforms PSICOV, CCMpred, DeepCov, and ResPRE at every distance and prediction count on both CASP datasets
- Pipeline run produces output files in ./contact_pred (and ./ss_pred for the multitask model)
- Training converges within the documented budget: approximately 2-3 days on an NVIDIA TITAN GTX GPU with ADAM, learning rate 0.0005, batch normalization, one domain per batch
- Contact definition check: predicted positives correspond to Cβ-Cβ distances < 8 Å (Cα for glycine)

## Limitations

- Network depth was capped at 60 layers because of GPU memory limitations
- Cropping sequences to 200 residues and sampling 30,000 MSA sequences discards information for longer/deeper inputs
- For shallow MSAs, covariance features alone may underperform on long-range contacts; adding sequence/MSA-derived features was reported as useful
