# multi-task-protein-structure-prediction

## Summary

Train and run DeepECA's multitask network, which jointly predicts protein contacts, secondary structure, and solvent-accessible surface area (ASA) from a single MSA using a shared 20-residual-block trunk with task-specific 10-block heads, so that the auxiliary 1D tasks improve overall representation and prediction accuracy.

## When to use

Use when predicting secondary structure, solvent accessibility, or residue-residue contacts from a protein sequence via its MSA, or when benchmarking 1D/2D structure prediction against RaptorX-Property and SCRATCH-1D on CASP targets.

## When NOT to use

- The goal is tertiary structure construction only — build models from contacts separately using CONFOLD with the top 2L contacts instead
- No HHblits setup or MSA can be generated (e.g., no UniProt20_2016 database available), since the multitask model consumes MSA-derived 2D feature maps
- The evaluation requires RaptorX-Contact local execution — RaptorX-Contact has no local execution file and runs only on its web server with different MSAs

## Inputs

- Protein amino-acid sequences in FASTA format (placed in ./dataset/fasta)
- Multiple sequence alignments generated by HHblits (three iterations, E-value 0.001, 60% coverage, UniProt20_2016)
- Pre-trained multitask models from the DeepECA Google Drive folder (for prediction)
- Training datasets with DSSP-assigned secondary structure from the Google Drive folder (for training)

## Outputs

- Contact prediction files in ./contact_pred
- Secondary structure and ASA prediction files in ./ss_pred
- Benchmark accuracy tables (Tables 4-6) comparing secondary-structure and ASA accuracy on CASP11 and CASP12

## How to apply

Download the pre-trained models and training datasets from the DeepECA Google Drive folder, then generate MSAs with HHblits using three iterations, E-value 0.001, 60% coverage, and the UniProt20_2016 library (set the hhblits path in run_hhblits_local.py). Train via multitask.py: a shared 20-residual-block trunk with task-specific 10-block heads, ADAM optimizer at learning rate 0.0005, batch normalization, one domain per batch, 200-residue cropping, and sampling of up to 30,000 MSA sequences (2-3 days on an NVIDIA TITAN GTX GPU); the rationale is that jointly learning secondary structure and ASA alongside contacts yields a better 2D feature representation. For prediction, run pipeline.py so outputs land in ./contact_pred and ./ss_pred, optionally placing custom FASTA files in ./dataset/fasta. Evaluate on CASP11 (105 domains) and CASP12 (55 domains), comparing secondary-structure accuracy and ASA accuracy against RaptorX-Property and SCRATCH-1D.

## Evaluation signals

- The multitask model's secondary-structure accuracy exceeds that of RaptorX-Property and SCRATCH-1D on CASP11 (105 domains) and CASP12 (55 domains)
- The multitask model achieves the highest ASA prediction accuracy among the three methods on both CASP11 and CASP12 (Table 6)
- Prediction result files are present in both ./contact_pred and ./ss_pred after running pipeline.py
- Training converges within the expected 2-3 days on an NVIDIA TITAN GTX GPU with the stated ADAM/lr 0.0005 configuration
- MSAs are generated with HHblits using three iterations, E-value 0.001, and 60% coverage against UniProt20_2016

## Limitations

- Network depth was capped at 60 layers (20 trunk + task-specific heads) because of GPU memory limitations
- Contact training used 200-residue cropping and sampling of at most 30,000 MSA sequences, constraining the input sizes per batch
- For 3 of 105 CASP11 domains and 1 of 55 CASP12 domains, RaptorX comparison results were missing due to server errors
- Training from scratch takes 2-3 days on an NVIDIA TITAN GTX GPU and requires the Google Drive models/datasets and a configured HHblits path
