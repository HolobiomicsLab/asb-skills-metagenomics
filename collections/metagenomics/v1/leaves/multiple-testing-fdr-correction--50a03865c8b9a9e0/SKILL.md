# multiple-testing-fdr-correction

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Applies multiple-testing correction (false discovery rate control) when ranking thousands of fungal taxa–metadata associations, so only associations surviving FDR < 0.05 are reported as significant.

## When to use

Use when a multivariable association analysis (e.g. MaAsLin2 on the FunOMIC-derived 2,679-sample abundance tables) tests many fungal taxa against many metadata variables and raw p-values must be corrected before calling significance.

## When NOT to use

- When only a single hypothesis or a small pre-specified set of taxa–metadata tests is performed — correction would only reduce power without meaningfully changing the error rate
- When the abundance table has not yet been generated by FunOMIC-T/FunOMIC-P mapping; this skill corrects association results, it does not produce the feature matrix
- For descriptive network visualization, which in this paper was filtered on raw p-values (<0.001) and absolute correlation coefficient >0.05 rather than FDR

## Inputs

- MaAsLin2 association results table (all tested fungal species–metadata pairs with coefficients, p-values, and correction status)
- Fungal taxonomic abundance feature matrix from FunOMIC-T mapping of the 2,679 metagenomic samples
- Fungal functional abundance feature matrix from FunOMIC-P mapping
- Sample metadata from Supplementary Table S2 (continent, country, city, sample source, gender, age, extraction procedure, use of mechanical lysis)

## Outputs

- Filtered table of significant associations at FDR < 0.05, ranked by coefficient/significance
- maaslin2_significant_associations.tsv (e.g. Yarrowia lipolytica positively associated with bead-beating)

## How to apply

Run the MaAsLin2 association analysis in R (version 4.1.2) with each metadata variable (continent, country, city, sample source, gender, extraction procedure, bead-beating/mechanical lysis, disease cohorts such as CD/UC/T1D/T2D/ESRD) as a fixed effect and age as the random effect, letting MaAsLin2 apply its default multiple-testing correction. Then filter the MaAsLin2 results to significant associations at FDR < 0.05. Rank surviving fungal species–metadata associations by coefficient and significance and write them to maaslin2_significant_associations.tsv. The rationale is that thousands of taxa are tested against many metadata variables simultaneously, so raw p-value thresholds would yield an uncontrolled false-positive rate; FDR control bounds the expected proportion of false discoveries among reported associations.

## Related tools

- **MaAsLin2** (Multivariable linear-model association testing whose default multiple-testing correction supplies the FDR-adjusted significance calls)
- **R** (Execution environment (version 4.1.2) in which the MaAsLin2 association models and FDR filtering are run)
- **FunOMIC** (Produces the FunOMIC-T taxonomic and FunOMIC-P functional abundance tables whose taxa–metadata tests are corrected for multiple comparisons) — https://github.com/ManichanhLab/FunOMIC

## Examples

```
fit <- MaAsLin2::MaAsLin2(input_data = fungal_abundance, input_metadata = meta, output = "maaslin2_out", fixed_effects = c("country","health_status","sample_source"), random_effects = c("age")); sig <- subset(fit$results, qval < 0.05)
```

## Evaluation signals

- Every row in maaslin2_significant_associations.tsv has an adjusted p-value (FDR) < 0.05; no raw-p-only rows survive
- The unfiltered MaAsLin2 output contains more rows than the filtered table, confirming correction plus filtering was actually applied rather than raw p-value thresholding
- Each significant association carries a non-null coefficient sign consistent with the reported direction (e.g. Yarrowia lipolytica positive with bead-beating)
- The random effect (age) appears in the model specification, matching the paper's setup of fixed metadata effects plus age as a random effect
- Output file is a well-formed TSV with species, metadata variable, coefficient, p-value, and FDR columns

## Limitations

- MaAsLin2's default multiple-testing correction is applied globally; grouping or stratifying tests differently would change which associations pass FDR < 0.05
- Associations that fail the FDR < 0.05 threshold (e.g. weaker geography or body-site signals) should not be reported as significant even if their raw p-values are small
- The FDR-corrected association step does not itself address technical confounders such as bacterial contamination of functional annotation, which the paper notes was 'not totally preventable'
