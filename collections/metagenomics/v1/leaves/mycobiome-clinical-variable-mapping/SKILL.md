# mycobiome-clinical-variable-mapping

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Reproduce multivariable association testing (MaAsLin2, R 4.1.2) linking FunOMIC-derived fungal taxonomic/functional abundance profiles of 2,679 human metagenome samples to clinical and demographic metadata, identifying significant species–metadata associations at FDR < 0.05.

## When to use

Use when fungal taxonomic or functional abundance tables (e.g. from FunOMIC-T/FunOMIC-P profiling) must be tested for significant associations with metadata variables such as health status, country, body site, or DNA extraction method.

## When NOT to use

- Input is raw sequencing reads rather than a FunOMIC-derived abundance table — profile reads with FunOMIC first (FunOMIC.sh) before association testing.
- The study design lacks repeated measures or covariates suited to MaAsLin2's fixed/random-effect formulation; a simple univariate test would suffice.
- Sample metadata is not available or cannot be joined to the abundance table by sample identifier.

## Inputs

- Fungal taxonomic abundance table from FunOMIC-T mapping of 2,679 metagenomic samples
- Fungal functional abundance table from FunOMIC-P mapping
- Sample metadata table (Supplementary Table S2: continent, country, city, sample source, gender, age, extraction procedure, mechanical lysis use)

## Outputs

- Ranked table of significant fungal species–metadata associations at FDR < 0.05 (maaslin2_significant_associations.tsv)

## How to apply

Join the FunOMIC-T fungal taxonomic abundance table and/or FunOMIC-P functional abundance table (generated by mapping NGS reads to the two built-in databases) with sample metadata (continent, country, city, sample source, gender, age, extraction procedure, use of mechanical lysis) from Supplementary Table S2. In R (version 4.1.2), run MaAsLin2 with each metadata variable as a fixed effect and age as a random effect, using MaAsLin2's default multiple-testing correction. Filter results to significant associations at FDR < 0.05, then rank significant fungal species–metadata associations (geography, body site, disease cohorts such as CD/UC/T1D/T2D/ESRD, bead-beating extraction) by coefficient and significance. The published analysis recovered, for example, a positive association of Yarrowia lipolytica with bead-beating, attributed to its higher cell-wall chitin fraction (10.3–18.9%).

## Related tools

- **MaAsLin2** (Multivariable linear-model association testing of fungal features against metadata variables with default multiple-testing correction)
- **FunOMIC** (Source pipeline producing the fungal taxonomic (FunOMIC-T) and functional (FunOMIC-P) abundance matrices used as association-testing features) — https://github.com/ManichanhLab/FunOMIC
- **R** (Analysis environment (version 4.1.2) in which MaAsLin2 is run and results are filtered and ranked)

## Examples

```
Rscript -e 'library(MaAsLin2); fit <- MaAsLin2(input_data=fungal_abund, input_metadata=meta, fixed_effects=c("country","health_status","bead_beating"), random_effects="age", output="maaslin2_out")'
```

## Evaluation signals

- All retained associations pass FDR < 0.05 under MaAsLin2's default multiple-testing correction.
- Age is specified as the random effect and each metadata variable as a fixed effect, matching the published model design.
- Output table maaslin2_significant_associations.tsv contains species, metadata variable, coefficient, and significance columns, ranked by coefficient/significance.
- Known biology is recoverable: Yarrowia lipolytica, one of the most prevalent and abundant fungal species, appears positively associated with bead-beating extraction.
- Feature matrices cover the same 2,679 human metagenome samples as the published FunOMIC analysis and join cleanly to Supplementary Table S2 metadata.

## Limitations

- FunOMIC's marker-gene extraction depends on completeness of available fungal genomes, giving lower fungal taxonomy coverage than amplicon databases — associations are limited to detectable taxa.
- The published analysis does not include a bacterial read filtration step before functional annotation; bacterial contamination of functional profiles was not totally preventable despite strict mapping thresholds.
- Significant associations (e.g. Y. lipolytica with bead-beating) may reflect extraction bias (cell-wall chitin fraction 10.3–18.9%) rather than true host or disease biology.
