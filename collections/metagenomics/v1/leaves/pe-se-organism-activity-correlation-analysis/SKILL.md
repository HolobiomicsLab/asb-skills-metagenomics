# pe-se-organism-activity-correlation-analysis

## Summary

Quantifies how much annotation information is lost when paired-end metatranscriptome reads are processed as simulated single-end reads, comparing QC removals, reference-database match rates, unique transcript counts, and organism-level activity correlations within the SAMSA/MG-RAST pipeline.

## When to use

Use when deciding whether paired-end sequencing is required for metatranscriptome read annotation, e.g. raw paired-end FASTQ files are available and the goal is to measure annotation loss from simulated single-end processing.

## When NOT to use

- Sequences are already short single-end reads below 100 bp — the paper states sequences need to be either long reads (>100 bp) or joined paired-end reads, so no meaningful PE-vs-SE comparison is possible
- The goal is an accurate measurement of microbial population size shifts — the paper notes metatranscriptomics 'cannot be measured as accurately as using shotgun metagenomics'
- Eukaryote-focused metatranscriptomes — MG-RAST (the annotation engine for this comparison) 'is not tailored to work with eukaryotic organisms'

## Inputs

- Raw paired-end metatranscriptome FASTQ files (pilot fecal metatranscriptome samples)
- Simulated single-end FASTQ files generated by Trimmomatic 100-bp trimming
- MG-RAST v3.6 organism-level annotation results files
- Organism summary files produced by analysis_counter.py and RefSeq_output_reducer.py

## Outputs

- table_2_pe_se_comparison.csv with QC removal counts (51,507 PE vs 123,518 SE; 0.3% vs 0.6%), reference match percentages (77.2% PE vs 65.9% SE), and unique transcripts (270,384 PE vs 215,599 SE)
- Per-sample organism summary/abundance files for both PE and SE versions
- PE-vs-SE organism activity correlation value from R_organism_script.Rmd/DESeq2 (expected average ≈ 0.72)

## How to apply

From raw paired-end FASTQ files, generate simulated single-end versions by trimming each read to 100 bp with Trimmomatic. Run both the original paired-end set (with paired-end joining by FLASH) and the simulated single-end set through SAMSA preprocessing — cleaning and adaptor-contamination removal with Trimmomatic, FLASH joining only for the PE set — then submit both to the MG-RAST annotation server (version 3.6). Download annotation results and aggregate them with SAMSA's analysis_counter and RefSeq_output_reducer.py. Compute the comparison metrics: reads removed by QC, percentage of reads matching the reference database, and unique transcripts identified. Finally, correlate organism-level activity summaries between the PE and SE results in R using R_organism_script.Rmd with DESeq2. The rationale is that joined paired-end reads recover sequence length (the paper recommends reads longer than 100 bp or joined PE reads) that single-end truncation discards, reducing read loss and raising match rates.

## Related tools

- **Trimmomatic** (Trims paired-end reads to 100 bp to create the simulated single-end files, and removes adaptor contamination in preprocessing for both versions)
- **FLASH** (Joins the original paired-end files during SAMSA preprocessing before MG-RAST submission (not applied to the simulated single-end set))
- **MG-RAST** (Annotation server (version 3.6) used to generate organism-level annotations for both the PE and SE file sets)
- **SAMSA** (Pipeline whose analysis_counter and RefSeq_output_reducer.py scripts aggregate MG-RAST results into organism summary files) — github.com/transcript/SAMSA
- **DESeq2** (R package used with R_organism_script.Rmd to statistically compare and correlate organism-level activity between PE and SE results) — github.com/transcript/SAMSA

## Examples

```
python RefSeq_output_reducer.py <organism_summary_in> <reduced_out>   # see README: run with '-usage' flag for program-specific inputs
```

## Evaluation signals

- QC removal counts match the published expectation: 51,507 reads (0.3%) removed for paired-end vs 123,518 (0.6%) for simulated single-end
- Reference-database match percentage matches 77.2% for PE vs 65.9% for SE
- Unique transcripts identified match 270,384 (PE) vs 215,599 (SE), confirming PE recovers more annotations
- Average organism-activity correlation between PE and SE results in R/DESeq2 is approximately 0.72
- All comparison metrics are present in table_2_pe_se_comparison.csv without missing rows for any sample

## Limitations

- MG-RAST annotation servers require waiting in a queue, and processing may be slowed by days to weeks
- The correlation (~0.72) indicates SE processing still loses a non-trivial fraction of annotation information, so SE results should not substitute for PE in annotation-sensitive analyses
- MG-RAST is not tailored to eukaryotic organisms, raising mismatch rates for eukaryotic metatranscriptomes
