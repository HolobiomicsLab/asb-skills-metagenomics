# peptide-spectrum-matching-with-blind-modifications

## Summary

A peptidogenomics scoring skill in which tandem MS spectra from GNPS datasets are searched against target and decoy databases of putative RiPP precursor peptides using a modified Dereplicator scoring function that permits blind (unspecified) post-translational modifications while penalizing matches with more than one modification, with FDR controlled by the target-decoy approach at 1%.

## When to use

Use when tandem mass spectra are paired with genomic/metagenomic data and you need to identify RiPPs—including those with unknown or blind modifications—by peptidogenomic database search at controlled FDR.

## When NOT to use

- The spectra are not accompanied by paired genomic/metagenomic data (about 99% of GNPS spectra cannot be searched this way)
- The RiPP of interest is a cyclic peptide — blind modification searches are not performed for cyclic peptides due to inherent computational complexity
- The producer genome is unavailable and no previously described biosynthetic gene cluster exists — the lacticin case required searching against a described BGC instead

## Inputs

- GNPS tandem mass spectrometry spectral datasets (e.g., MSV000079506, MSV000079622, MSV000078839, MSV000078604, MSV000078552, MSV000080102) with paired genomic or metagenomic data
- Assembled genomic/metagenomic contigs (or short reads to be assembled into contigs)
- Target RiPP precursor peptide database from motif-ORF and all-ORF strategies
- Decoy RiPP precursor peptide database generated by random shuffling of target peptides

## Outputs

- Peptide-spectrum matches with p-values (computed with MS-DPR)
- FDR-estimated RiPP identifications surviving a 1% FDR threshold per dataset
- Expanded RiPP identification set via spectral networks
- Curated table of identified RiPPs (e.g., 38 RiPPs: 31 known including AIP, Mec-PSM, delta-toxin, polytheonamide, wewakazole, lichenicidin, plus 7 unknown RiPPs)

## How to apply

First build the search space: 6-frame translate the contigs from assembled short reads, construct putative RiPP precursor peptides via the motif-ORF and all-ORF strategies (all-ORF mode flags ORFs shorter than the default 200-amino-acid threshold), run HMMer to detect modification enzymes, and delimit each putative biosynthetic gene cluster as a 10kbp window centered on each detected enzyme. Then create a decoy database by randomly shuffling each peptide in the target precursor database. Search the spectra against both target and decoy RiPP databases using a modified Dereplicator scoring function that performs blind modification search, restricting the number of modifications via dynamic programming and penalizing high-score matches with more than one modification. Compute peptide-spectrum match p-values with MS-DPR, estimate FDR with the target-decoy approach, apply a 1% FDR threshold per dataset, and enlarge the identification set via spectral networks before curating the final RiPP table.

## Related tools

- **Dereplicator** (Modified version used to search spectra against the database of putative target/decoy RiPPs with blind-modification-aware scoring)
- **MS-DPR** (Computes p-values of the peptide-spectrum matches)
- **MetaMiner** (End-to-end peptidogenomics pipeline that builds the target/decoy precursor databases and invokes the modified Dereplicator search; available as command-line tool and GNPS RIPPQUEST workflow) — https://github.com/mohimanilab/MetaMiner
- **GNPS** (Source of mass spectrometry datasets and hosting platform for the MetaMiner (RIPPQUEST) workflow)

## Evaluation signals

- Composition of the curated table matches the reported 38 RiPPs (31 known + 7 unknown) at the 1% FDR threshold from 10 million spectra
- In the positive control dataset of isolated RiPPs, all 18 known RiPPs are correctly identified
- Estimated FDR via target-decoy approach remains at or below 1% for each dataset
- Seven novel RiPPs (three lanthipeptide, one lassopeptide, two peptide-spectrum matches and one cyclic cyanobactin) are recovered from the eight spectral datasets
- Spectral networking expands the surviving PSM set with analogs in the same spectral families (10 million spectra cluster into 8071 families)

## Limitations

- Only 38 RiPPs were identified from 10 million spectra, because many spectral families belong to non-RiPP compound classes (e.g., non-ribosomal peptides per Dereplicator+ analysis)
- No blind modification searches are performed for cyclic peptides due to inherent computational complexity
- The motif-ORF strategy is not sensitive and misses precursor peptides lacking sequence similarity to known RiPPs
- Spectra lacking paired genomic/metagenomic data (the other 99% of GNPS) cannot be searched
