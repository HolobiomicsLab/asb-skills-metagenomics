# population-genomics-subworkflow-execution

## Summary

Executes the scalepopgen Nextflow pipeline end-to-end, dispatching its four sub-workflows (filtering/basic statistics, genetic structure, TreeMix phylogeny, and signatures of selection) on biallelic SNP data in VCF or PLINK binary format, with MultiQC compiling results into a consolidated HTML report.

## When to use

Use when a genome-wide biallelic SNP dataset (VCF or PLINK binary) needs comprehensive population genomic analysis — filtering, PCA/ADMIXTURE structure, TreeMix phylogeny, and selection scans — in a single automated reproducible run.

## When NOT to use

- The analysis requires only a single specific statistic or tool run rather than the integrated multi-sub-workflow framework the pipeline provides
- Input data are multi-allelic variants, non-SNP variants, or unsplit/unindexed VCFs not prepared per the chrom,vcf,vcf_idx sheet format
- No Linux environment or container engine (conda/mamba/singularity/docker) is available, since the pipeline requires Nextflow, Java, and one of these

## Inputs

- Chromosome-split, tabix-indexed VCF files listed in a vcf_input.csv sheet (chrom,vcf,vcf_idx header)
- PLINK binary files (bed/bim/fam) listed in a plink_input.p.csv sheet (prefix,bed,bim,fam header)
- Tab-delimited sample map file (.map) with individual IDs and population IDs, no header
- YAML parameters file generated via scalepopgen-cli
- Nextflow profile selection (test, test_full, docker/singularity/conda/mamba)

## Outputs

- Final MultiQC HTML report compiling visualizations of all analyses
- HTML execution report with per-process resource usage and timing
- Filtering and summary statistics results (MAF, observed/expected heterozygosity)
- Genetic structure outputs (PCA plots, ADMIXTURE Q-matrices with CV-error K selection)
- TreeMix phylogeny with OptM-identified optimal number of migration edges
- Selection-scan results (Tajima's D, Pi, FST, SweepFinder2, iHS/XP-EHH)
- citation_ folder with BibTeX references generated by the CLI

## How to apply

Clone the scalepopgen repository, install the three required dependencies (Nextflow, Java, and one container/environment system such as mamba, conda, singularity, or docker), and prepare input sheets: chromosome-split, tabix-indexed VCFs listed in a .csv with chrom/vcf/vcf_idx headers, or PLINK bed/bim/fam files in a .p.csv, plus a tab-delimited sample.map of individual and population IDs. Generate the YAML parameter file with the scalepopgen-cli, then launch the pipeline with nextflow run scalepopgen/ -profile <docker/singularity/conda/mamba> -params-file <path/to/parameters.yml>; use -profile test to validate setup on a minimal bundled dataset and -profile test_full to reproduce the paper's cattle results (442 samples, 30 breeds reduced to 269 samples, 17 breeds, ~23.4 million SNPs after filtering). The main DSL2 workflow dispatches sub-workflows in order: sample-then-site filtering with summary statistics (MAF, heterozygosity, LD pruning via Plink2), genetic structure (PCA, ADMIXTURE with CV-error-based K selection, IBS/FST), TreeMix with OptM migration-edge selection, and selection scans (Tajima's D, Pi, FST, SweepFinder2, iHS/XP-EHH on phased data). Python and R scripts collect results into interactive Plotly/Bokeh visualizations, and MultiQC (v1.19) compiles everything into a final HTML report including per-process resource usage. Validate by confirming the run completes without error and the HTML execution report documents successful completion of all four sub-workflows; the paper's full run took ~1.5 h wall time (~136 CPU hours).

## Examples

```
nextflow run scalepopgen/ -profile test,<docker/singularity/conda/mamba> -qs 10
```

## Evaluation signals

- The Nextflow run completes without error and the HTML execution report shows successful completion of all four sub-workflows
- MultiQC (v1.19) produces a final HTML report compiling visualizations from each analysis
- With -profile test_full, results are consistent with the paper's cattle benchmark: 442 samples/30 breeds reduced to 269 samples/17 breeds and ~23.4 million SNPs after sample- and site-filtering, and 129,357 SNPs after LD-based filtering
- The ADMIXTURE CV-error plot identifies a suitable K and Q-matrices are rendered (e.g., via pong or pophelper)
- The CLI-generated citation_ folder exists with BibTeX references for all tools used

## Limitations

- Only three dependencies are preinstalled; all other tools are downloaded automatically by Nextflow, so runs require network access and a working container/environment system
- VCF files must be split by chromosome and tabix-indexed, and chromosome names must not contain punctuation marks
- Filtering is applied in two steps with site filtering after sample filtering; LD pruning is recommended before analyses such as ADMIXTURE
- iHS/XP-EHH selection scans require phased input data
