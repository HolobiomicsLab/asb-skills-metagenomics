# random-effects-meta-analysis

## Summary

Random effects meta-analysis across multiple studies and related markers (mMeta) and its adaptive minimum-p-value companion (aMeta), implemented via the R package mMeta, using only study-by-marker effect estimates and standard errors without a priori marker-by-marker correlations.

## When to use

Use when combining K>=10 studies across multiple related markers (e.g., 6 alpha-diversity indices) from summary statistics only — effect estimates and standard errors — with no prior correlation or full-data access.

## When NOT to use

- Fewer than 10 studies: the mMeta.aMeta function requires the number of studies (rows of est/std.err) to be >= 10
- Full individual-level data are available and marker-by-marker correlations can be modeled directly — conventional multivariate meta-analysis on raw data is preferable
- Hypothesis testing requires accompanying effect-size estimation from aMeta: aMeta is limited to hypothesis testing with no estimation facilities (use mMeta for pooled estimates)

## Inputs

- data.frame or matrix of study-specific effect estimates (e.g., regression coefficients), rows = studies, columns = markers, NAs allowed at matched positions
- data.frame or matrix of study-specific standard errors, same dimensions and NA positions as 'est'
- Built-in example data: Sum.Data or HIV.Sum.Data (15 HIV studies x 6 alpha-diversity indices: Richness, Shannon, Simpson, PD, PE, PQE)

## Outputs

- Pooled estimates, 95% confidence intervals and p-values for each marker
- mMeta pooled estimate, 95% CI and p-value across markers
- aMeta p-value across markers based on the minimum-p-value statistic
- Optional forest plot per marker and across markers via mMeta.aMeta.plot
- Results table (e.g., CSV) of per-marker and across-marker estimates and p-values

## How to apply

Install the mMeta package from GitHub (install_github('hk1785/mMeta', force=T)) with forestplot, MASS and vegan, and supply a study-by-marker matrix of regression coefficient estimates ('est') and standard errors ('std.err'), allowing matched NA entries for missing summary data. Call mMeta.aMeta(est, std.err, seed=123), which fits per-marker random effects meta-analyses using the SJ heterogeneity-variance estimator; set tau0=FALSE to apply Han and Eskin's modification assuming no heterogeneity under H0. The null distribution for p-values is generated by the Follmann-Proschan sign-flipping group permutation method with n.perm=5000 (all 2^K permutations when the number of studies is <15, in which case 'seed' is ignored). mMeta pools the estimates across studies and markers accounting for estimated marker-by-marker correlations, while aMeta tests the minimum marker-specific p-value against its group-permutation null. Extract pooled estimates, 95% confidence intervals and p-values per marker and across markers; optionally draw forest plots with mMeta.aMeta.plot.

## Examples

```
library(mMeta); data(HIV.Sum.Data); out <- mMeta.aMeta(HIV.Sum.Data$est, HIV.Sum.Data$std.err, seed=123); out
```

## Evaluation signals

- Run with seed=123 and confirm results are reproducible across repeated calls
- Verify the aMeta p-value is smaller than the mMeta p-value in the HIV data application, matching Figure 3 and Table S2 ordering (aMeta approaches the highest power of marker-specific meta-analyses)
- Confirm output object contains non-empty pooled estimates, 95% CI bounds and p-values for every marker despite matched NA entries in est/std.err
- Check that the group permutation method yields smaller p-values / higher power than the parametric asymptotic-normality method (mu_hat/sigma_mu ~ N(0,1)), consistent with Figure 1 and Table S2
- Under null simulations, type I error rates should be at most 5% at the 5% significance level (Table 3)

## Limitations

- Requires at least K = 10 studies per marker; number of rows of est and std.err must be >= 10
- Requires only effect estimates and their standard errors, but these summary statistics are hard to obtain in practice — many studies report only graphs or stratified summary statistics (mean, median, IQR per group)
- aMeta provides no estimation facilities — it is limited to hypothesis testing
- Effect estimates and standard errors must have NA entries at matched positions between 'est' and 'std.err'
- No set criteria for selecting candidate markers; selection rules should be documented for readers
- When the number of studies < 15, all 2^K possible permutations are implemented and n.perm/seed are ignored, which may be computationally heavy for moderate K
