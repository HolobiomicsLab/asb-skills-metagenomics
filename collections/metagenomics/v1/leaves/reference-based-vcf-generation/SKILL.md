# reference-based-vcf-generation

## Summary

Converts reference-free variant calls (the KisSNP2-format .snp output of ebwt2InDel) into standard .vcf entries by anchoring variant fragments onto a reference genome. It uses the snp2vcf pipeline: filter_snp -> seqtk -> bwa-mem -> sam2vcf.

## When to use

Use when reference-free variant calls exist as .snp files (ebwt2InDel output) and a reference genome assembly (e.g. hg38) is available, so variants must be converted to .vcf with reference coordinates.

## When NOT to use

- No reference genome is available — the ebwt2InDel suite itself is reference-free, and this conversion pipeline requires aligning against an assembly such as hg38
- The variant calls already come as .vcf (e.g. validated with hap.py) — no snp2vcf conversion is needed
- The parallel pipeline is being used for INDELs — the article notes the parallel pipeline 'at the moment works for SNPs only'

## Inputs

- calls.snp / output.snp file (KisSNP2-format variant contexts from ebwt2InDel)
- Minimum-coverage threshold m (e.g. 5 reads for >= 25x datasets)
- Reference genome assembly FASTA (e.g. hg38 Human assembly)

## Outputs

- Filtered calls file (output.5.snp)
- FASTQ file of variant fragments with fake base qualities (calls.fastq)
- SAM alignment of variant fragments against the reference
- variants.vcf with reference-coordinate SNP/INDEL entries

## How to apply

First filter the .snp file produced by ebwt2InDel with filter_snp, keeping only SNP/INDEL events covered by at least m reads (m=5 is the value used for datasets covered at >= 25x), yielding output.5.snp. Convert the filtered call file to FASTQ with fake base qualities using seqtk (seq -F 'I') so the variant contexts can be treated as sequencing reads. Align these variant fragments against the reference assembly (e.g. the hg38 Human assembly) with bwa mem to produce a SAM file, then run sam2vcf on the SAM to translate mismatch and INDEL alignment records into VCF entries at reference coordinates. The whole seqtk -> bwa-mem -> sam2vcf chain is automated as the snp2vcf script. Finally, because the dataset and its reverse-complement are both analyzed, remove duplicate entries from the .vcf files.

- **filter_snp** (Filters the .snp file generated by ebwt2InDel to keep only SNP/indels covered by at least m reads before conversion) — github.com/nicolaprezza/ebwt2InDel

## Examples

```
filter_snp output.snp 5 > output.5.snp
```

## Evaluation signals

- variants.vcf exists and parses as a valid VCF
- VCF entries carry reference coordinates on the chosen assembly (e.g. hg38) corresponding to events present in the filtered calls.snp
- The filtered calls file (output.5.snp) contains only events supported by at least m=5 reads
- Duplicate VCF entries (same variant found on forward and reverse strands) have been removed
- Calls can be benchmarked against ground truth with hap.py, as done against the NCBI GIAB NA12878_HG001 VCF

## Limitations

- The parallel pipeline at the moment works for SNPs only; INDEL support was deferred to a forthcoming update
- Real-data evaluation relied on an approximated ground truth, lowering precision estimates
- Low-coverage variants are discarded at post-processing time, so threshold choice (m) trades sensitivity for reliability
