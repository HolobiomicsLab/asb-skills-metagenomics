# residual-dnn-contact-prediction-training

## Summary

Trains a 60-layer residual network with the ADAM optimizer (learning rate 0.0005) and batch normalization to predict protein contacts end-to-end from covariance matrices computed on HHblits-generated MSAs, so that even this baseline outperforms existing ECA methods on CASP11/CASP12.

## When to use

Use when you need to train (or retrain) an end-to-end DNN contact predictor from an MSA, e.g. reproducing the DeepECA Baseline Model rows of the CASP11/CASP12 precision tables.

## When NOT to use

- You only need to run inference with the released pre-trained model — use pipeline.py directly rather than retraining.
- The target proteins exceed 700 residues or are shorter than 25 residues, or lack DSSP-assignable secondary structure for ≥80% of residues, since such proteins were excluded from the training dataset.
- A local, non-DNN ECA method (e.g. PSICOV, CCMpred) suffices — this skill is for end-to-end DNN training, not graphical-lasso/pseudolikelihood estimation.

## Inputs

- Protein FASTA sequences placed in ./dataset/fasta
- MSAs generated by HHblits (three iterations, E-value 0.001, 60% coverage)
- Covariance matrices computed from the MSAs (input features, cropped to 200 residues, up to 30,000 MSA sequences sampled)
- Pre-trained models and training datasets from the Google Drive folder

## Outputs

- Trained 60-layer residual network model (one domain per batch)
- Contact predictions stored in ./contact_pred
- Secondary-structure / related predictions stored in ./ss_pred (multitask model)

## How to apply

Download the pre-trained models and training datasets from the authors' Google Drive folder, and set up HHblits. Generate MSAs with three HHblits iterations against UniProt20_2016 at E-value 0.001 and 60% coverage, compute covariance matrices from the MSAs as DNN input features, cropping protein sequences to 200 residues and sampling 30,000 MSA sequences when more are available. Train the 60-layer residual network (depth constrained by GPU memory) using multitask.py with the ADAM optimizer at learning rate 0.0005, batch normalization, and one domain per batch, which takes about 2-3 days on an NVIDIA TITAN GTX GPU. Then run pipeline.py to predict contacts, with results written to the ./contact_pred directory. Contacts are defined as Cβ–Cβ pairs within 8 Å (Cα for glycine).

## Related tools

- **DeepECA** (Framework providing multitask.py (training) and pipeline.py (prediction) for the 60-layer residual contact-prediction network) — https://github.com/tomiilab/DeepECA
- **HHblits** (Generates the MSAs (three iterations, E-value 0.001, 60% coverage) from which covariance-matrix input features are computed; path must be edited in run_hhblits_local.py)

## Examples

```
python multitask.py
```

## Evaluation signals

- Evaluate precision TP/(TP+FP) at top L/10, L/5, L/2 and L predicted pairs for short, medium and long sequence-separation ranges on CASP11 (105 domains) and CASP12 (55 domains).
- Confirm the trained Baseline Model's precision values match the Baseline rows of Tables 11 and 12.
- Verify the Baseline Model outperforms PSICOV, CCMpred, DeepCov, and ResPRE at every distance and prediction count on both CASP11 and CASP12.
- Training completes within the expected ~2-3 day runtime on an NVIDIA TITAN GTX GPU.
- Predictions are correctly written to the ./contact_pred directory after running pipeline.py.

## Limitations

- Network depth was fixed at 60 layers because of GPU memory limitations.
- Training requires the pre-downloaded datasets/models from the Google Drive folder and a correctly configured HHblits path in run_hhblits_local.py.
- Training takes 2-3 days on an NVIDIA TITAN GTX GPU; TensorFlow r1.11.0 on Ubuntu 16.04 was the tested environment.
