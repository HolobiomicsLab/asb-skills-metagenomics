# sam-to-vcf-variant-annotation

## Summary

Converts reference-free SNP/INDEL calls (e.g. the KisSNP2-format .snp output of ebwt2InDel) into standard .vcf records by realigning variant fragments to a reference assembly. The paper's snp2vcf pipeline — seqtk → bwa-mem → sam2vcf — translates mismatches and INDELs in a SAM alignment into reference-coordinate VCF entries.

## When to use

Use when a variant caller outputs reference-free calls (e.g. ebwt2InDel's .snp fasta) and a reference genome (e.g. hg38) is available, so calls must be expressed as coordinate-anchored .vcf entries for validation or downstream use.

## When NOT to use

- No reference genome is available for the organism — the whole point of ebwt2InDel is reference-free discovery, and this skill requires aligning variant fragments to hg38 (or an equivalent reference).
- The input is already a valid VCF or alignment-coordinate callset rather than a KisSNP2-format .snp/fasta of variant contexts.
- The .snp calls have not been low-coverage filtered when coverage is marginal — the paper suggests filter_snp with m=5 only for datasets covered at >=25x.

## Inputs

- .snp file of SNP/INDEL calls in KisSNP2 format produced by ebwt2InDel (optionally filtered with filter_snp at threshold m, e.g. 5 reads)
- Reference genome assembly in FASTA format (paper uses the hg38 Human assembly)
- Reference index for bwa mem

## Outputs

- calls.fastq: FASTQ of variant fragments with fake base qualities ('I')
- calls.sam: bwa mem alignment of variant fragments against the reference
- variants.vcf: VCF with reference-coordinate SNP/INDEL entries (duplicates from forward/reverse strand detection removed)

## How to apply

First, optionally filter the .snp file generated by ebwt2InDel with filter_snp so only SNP/INDEL events covered by at least m reads are kept (the paper uses m=5 for datasets covered at >=25x: 'filter_snp output.snp 5 > output.5.snp'). Convert the filtered calls to FASTQ with fake base qualities using seqtk (seq -F 'I'), producing calls.fastq. Align the variant fragments in calls.fastq against the reference assembly (the paper uses bwa mem against the hg38 Human assembly), yielding a SAM file, then translate the SAM's mismatch and INDEL records into VCF entries with sam2vcf. The whole chain seqtk → bwa-mem → sam2vcf is referred to in the paper as the snp2vcf pipeline and can be automated with the snp2vcf.sh script. Remove duplicate VCF entries afterwards if the dataset and its reverse-complement were both analyzed, since variants can be found twice.

## Related tools

- **filter_snp** (Pre-filters the ebwt2InDel .snp output to keep only SNP/INDELs covered by at least m reads before conversion) — github.com/nicolaprezza/ebwt2InDel
- **seqtk** (Converts the filtered call file to FASTQ with fake base qualities (seq -F 'I'))
- **bwa mem** (Aligns the variant fragments in calls.fastq to the hg38 Human reference assembly, producing a SAM file)
- **sam2vcf** (Translates mismatches and INDEL records in the SAM alignment into VCF entries)
- **hap.py** (Optionally validates the resulting VCF calls against a gold-standard truth set such as NCBI GIAB NA12878_HG001) — https://github.com/Illumina/hap.py

## Examples

```
bwa mem hg38.fa calls.fastq > calls.sam && sam2vcf calls.sam > variants.vcf
```

## Evaluation signals

- variants.vcf exists, parses as a valid VCF, and contains reference-coordinate entries corresponding to the events present in the filtered calls.snp.
- Every variant supported by at least m=5 reads in the filtered .snp file has a corresponding VCF record (compare event counts between output.5.snp and variants.vcf).
- VCF records map to expected hg38 coordinates when variant fragments are re-checked against the reference assembly.
- Duplicate entries (same variant found on both forward strand and reverse-complement of the dataset) are removed from the final .vcf.
- If benchmarking, hap.py against the NCBI GIAB NA12878_HG001 ground-truth VCF reports plausible sensitivity/precision.

## Limitations

- Real-data validation can rely on an approximated ground truth, lowering measured precision for both the tool and the VCF conversion.
- Variants can be reported twice (dataset and its reverse-complement), so deduplication of .vcf entries is required.
- The conversion anchors calls to a single reference (hg38 in the paper); variants in regions absent/divergent from the reference may not convert correctly.
