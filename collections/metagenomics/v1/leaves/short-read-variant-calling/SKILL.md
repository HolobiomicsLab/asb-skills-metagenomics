# short-read-variant-calling

## Summary

Reference-based variant discovery from standard short-read data: align NA12878/NA24385 Illumina reads to hg38 with BWA-MEM, call SNVs with FreeBayes and SVs with SvABA, process 10x Linked-Reads with Long Ranger, and benchmark all calls against GIAB with RTG vcfeval and truvari.

## When to use

Use when you have standard Illumina FASTQ or 10x Linked-Read FASTQ from a GIAB cell line and need benchmarkable SNV/SV call sets to compare against an alternative strategy such as assembly-based variant calling.

## When NOT to use

- When the goal is de novo assembly quality assessment rather than reference-based variant discovery (use assembly with Supernova2 instead)
- When no GIAB benchmark call set exists for the sample, since vcfeval/truvari benchmarking is central to validating the call sets
- When input data is simulated Linked-Reads generated by LRTK-SIM solely for assembly-parameter exploration; only SNV/SV variant output is needed, not coverage/contiguity simulation

## Inputs

- Standard Illumina paired-end FASTQ files from GIAB samples (NA12878, NA24385)
- 10x Chromium Linked-Read FASTQ files (barcoded R1/R2)
- hg38 human reference sequence (FASTA)
- GIAB benchmark VCF call sets and GIAB Tier 1 SV benchmark regions

## Outputs

- SNV VCF call sets from FreeBayes (Illumina alignments) and Long Ranger (10x libraries)
- SV call sets from SvABA and deletion calls from Long Ranger
- vcfeval concordance metrics (precision, recall, F1, genotype-aware matching)
- truvari concordance metrics against GIAB Tier 1 SV regions
- Per-sample concordance tables corresponding to Supplementary Tables S7–S14

## How to apply

Align NA12878 and NA24385 Illumina short reads to the hg38 reference with BWA-MEM, then call SNVs from the resulting BAMs with FreeBayes and SVs from the same alignments with SvABA. In parallel, process the 10x Chromium Linked-Read libraries through the Long Ranger pipeline to obtain SNV and deletion calls that exploit the barcode-derived long-range information. To benchmark, compare the SNV call sets to the GIAB benchmark using RTG vcfeval with genotype-aware matching, and compare SV call sets to GIAB Tier 1 SV regions with truvari, compiling precision, recall, and F1 per sample and caller. SV calls of interest (e.g., assembly-derived ones) can be further validated by aligning them to PacBio CCS long reads with VaPoR. In this study the resulting concordance statistics populated Supplementary Tables S7–S14 and showed reference-based Illumina and 10x SNV calls were comparably accurate and both outperformed SNVs derived from Supernova2 de novo assemblies.

## Related tools

- **BWA-MEM** (Aligns NA12878/NA24385 Illumina short reads to the hg38 reference)
- **FreeBayes** (Calls SNVs from the BWA-MEM Illumina alignments)
- **SvABA** (Calls structural variants from the same Illumina alignments)
- **Long Ranger** (10x official pipeline producing SNV and deletion calls from Linked-Read libraries) — https://support.10xgenomics.com/genome-exome/software/pipelines/latest/what-is-long-ranger
- **Supernova2** (Produces the de novo diploid assemblies from which assembly-based variant calls are compared against the reference-based call sets) — https://support.10xgenomics.com/de-novo-assembly/software/overview/welcome
- **RTG vcfeval** (Genotype-aware benchmarking of SNV call sets against GIAB)
- **truvari** (Benchmarks SV call sets against GIAB Tier 1 SV regions)
- **VaPoR** (Validates SV calls by aligning them to PacBio CCS long reads)

## Evaluation signals

- vcfeval concordance statistics (precision, recall, F1) for NA12878 and NA24385 reproduce the GIAB-comparison values in Supplementary Tables S7–S14
- truvari benchmark against GIAB Tier 1 SV regions yields concordance values matching the reported tables for both samples
- VaPoR validation of assembly-derived SV calls against PacBio CCS reads reproduces the reported concordance
- Reference-based Illumina and 10x SNV call sets show comparable accuracy, and both exceed the accuracy of SNVs from Supernova2 de novo assemblies
- All FreeBayes/SvABA call sets are derived from BWA-MEM alignments to hg38, confirming no sample/reference mix-up

## Limitations

- Assembly-based SNV calls were less accurate than reference-based calls, so the reference-based route should be preferred when a high-quality reference exists
- No alternative assembler to Supernova2 was available, limiting interpretation of assembly-parameter effects on downstream variant calling
- VaPoR-based SV validation requires PacBio CCS long reads, which may not be available for all samples
