# Simulated-read microdiversity validation

## Summary

Validates inStrain's coverage, breadth, and nucleotide-diversity profiling module by mapping reads simulated at known coverage and mutation levels (pIRS, SNP Mutator) and checking that observed metrics match ground truth, e.g. ~100% breadth at 20x coverage.

## When to use

Use when a metagenomic profiling module's coverage-, breadth-, or nucleotide-diversity outputs must be validated against a reference genome with known simulated mapping properties before trusting real-sample results.

## When NOT to use

- Input .bam comes from real (non-simulated) reads with unknown true coverage/diversity — validation against ground truth is not possible
- Goal is strain-level comparison between profiles (use inStrain compare with ConANI/popANI instead of profiling validation)
- Only raw read coverage/abundance is needed without breadth or microdiversity metrics (a fast tool like CoverM suffices)

## Inputs

- Reference genome .fasta file
- Sorted .bam file of simulated reads mapped to the reference (generated by pIRS simulation at 20x coverage plus Bowtie2/Samtools alignment)
- Simulated mutation ground truth from SNP Mutator (known number of introduced mutations)

## Outputs

- scaffold_info.tsv (tab-separated) listing scaffold name, length, coverage, median coverage, breadth, unmasked breadth, expected breadth, and nucleotide diversity
- Per-scaffold validation comparison of observed vs. expected breadth (e.g. observed breadth ≈ 1 at 20x)

## How to apply

Map simulated reads to a reference .fasta with Bowtie2/Samtools and run the profiler (inStrain profile on a sorted .bam) on each scaffold, tallying per-position read depth and A/C/G/T base counts from properly paired primary alignments. Compute per-position nucleotide diversity as 1 minus clonality (the sum of squared A/C/G/T base frequencies) at positions with coverage above the min_cov threshold of 5 reads, and aggregate per-scaffold average/median coverage, breadth (fraction of bases covered by >=1 read), and unmasked breadth. Compare observed breadth against the inStrain expected-breadth model expectedBreadth = -1*e^(-0.883*coverage)+1 computed from mean coverage. Use pIRS to simulate Illumina reads at 20x coverage and SNP Mutator to introduce a known number of mutations into the reference genome so diversity metrics can be checked against known ground truth; the documented expectation is that 20x simulated mapping yields observed breadth ≈ 1 (every base covered by at least one read).

## Related tools

- **inStrain** (Profiles the mapped simulated reads, computing coverage, breadth, unmasked breadth, expected breadth, and nucleotide diversity per scaffold) — github.com/MrOlm/instrain
- **Samtools** (Interacts with .bam files and calculates per-position read coverage over the reference sequence)
- **Numpy** (Computes per-position nucleotide diversity as 1 minus clonality (sum of squared A/C/G/T base frequencies) at positions above min_cov)
- **Pandas** (Assembles per-scaffold metrics into the tabular scaffold_info.tsv output)
- **pIRS** (Simulates Illumina reads at 20x coverage from reference genomes for validation)
- **SNP Mutator** (Introduces a known number of mutations into the reference genome to create known diversity ground truth)

## Examples

```
inStrain profile mapping.bam genome_file.fasta -o inStrain_profile1
```

## Evaluation signals

- scaffold_info.tsv contains all expected metric columns: scaffold name, length, coverage, median coverage, breadth, unmasked breadth, expected breadth, nucleotide diversity
- 20x simulated mapping yields observed breadth ≈ 1 (100% genome breadth; every base covered by at least one read), matching the documented expectation
- Observed breadth tracks the inStrain model expectedBreadth = -1*e^(-0.883*coverage)+1 across simulated coverage levels
- Nucleotide diversity is computed only at positions with coverage greater than the min_cov threshold of 5 reads
- Diversity metrics are consistent with the known number of mutations introduced by SNP Mutator into the simulated reference

## Limitations

- Variant sites near the ends of genome fragments can be missed with inStrain
- Genome de-replication at 98% ANI is needed to reduce multi-mapped reads, which otherwise corrupt coverage statistics
- Careful filtering of .bam reads (removing un-paired reads, requiring proper orientation/insert size, minimum mapQ and nucleotide identity) is required to avoid erroneously mapped reads inflating coverage
