# tmscore-structural-similarity-evaluation

## Summary

Reconstruct tertiary structure models from top-2L predicted residue-pair contacts plus predicted secondary structures using the CONFOLD package script, then score each model against its native CASP domain structure with TMscore to quantify fold-level reconstruction quality.

## When to use

Use when you have per-domain predicted contact lists and secondary structures (e.g., from a multitask contact predictor) and need to build 3D models and quantify their similarity to native structures via TMscore.

## When NOT to use

- You only have contact probabilities but no predicted secondary structures and no plan to use CONFOLD — the reconstruction step requires both as inputs
- The question is contact-prediction accuracy itself (e.g., top-L precision of ./contact_pred) rather than fold-level similarity of built 3D models
- Protein domains where expected mirror-image ambiguity is acceptable — a domain like T0845-D1 can have high contact accuracy (86.6%) yet a low TMscore of 0.276, so TMscore alone may mislead

## Inputs

- Predicted contact list per CASP domain (top 2L mixed-range residue pairs, from ./contact_pred)
- Predicted secondary structures per domain (from ./ss_pred)
- Native CASP domain structures (PDB) for TMscore comparison

## Outputs

- Reconstructed 3D model per CASP domain (PDB format, built by CONFOLD)
- Per-domain TMscore against the native structure
- Summary statistics: average TMscore per dataset and count of domains with TMscore > 0.5

## How to apply

Collect the predicted contacts from ./contact_pred and predicted secondary structures from ./ss_pred generated by running 'python pipeline.py' with the multitask model. For each CASP domain, select the top 2L mixed-range residue-pair contacts (L = domain length) as distance restraints. Run a script from the CONFOLD package with these contacts plus the predicted secondary structures as inputs to reconstruct a 3D model per domain. Compare each reconstructed model to its native CASP domain structure using TMscore, then aggregate per-domain scores; in the DeepECA evaluation this yielded average TMscores of 0.472 on CASP11 (105 domains) and 0.402 on CASP12 (55 domains), with TMscore > 0.5 for 50/105 and 18/55 domains respectively.

## Related tools

- **CONFOLD** (Package whose script builds 3D tertiary structure models from the top 2L predicted contacts and predicted secondary structures)
- **TMscore** (Scores each reconstructed model against its native CASP domain structure to measure fold similarity)
- **DeepECA** (Multitask model (run via 'python pipeline.py') producing the predicted contacts and secondary structures consumed by this workflow) — https://github.com/tomiilab/DeepECA

## Evaluation signals

- Computed average TMscore over CASP11 (105 domains) reproduces the reported 0.472
- Computed average TMscore over CASP12 (55 domains) reproduces the reported 0.402
- Domains with TMscore > 0.5 count to 50/105 on CASP11 and 18/55 on CASP12
- Per-domain sanity anchors: T0811-D1 TMscore 0.818 with 85.3% top-L contact accuracy and T0920-D1 TMscore 0.848 with 86.3%
- Failure-mode anchor: T0845-D1 shows 86.6% contact accuracy but only TMscore 0.276 (mirror-image model), so a high contact accuracy does not guarantee a high TMscore

## Limitations

- A mirror-image failure mode exists: T0845-D1 reached 86.6% contact accuracy yet only TMscore 0.276; more precise contact information would be necessary to solve such a mirror image-like problem
- The authors note that more sophisticated tertiary structure construction methods are necessary beyond the CONFOLD script used here
- The top 2L contacts used as restraints may be insufficient for accurate reconstruction on some domains
