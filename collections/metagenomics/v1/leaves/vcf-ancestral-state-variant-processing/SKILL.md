# vcf-ancestral-state-variant-processing

## Summary

Pipeline skill for extracting unfolded site frequency spectra and human-chimpanzee divergence counts from 1000GP Phase III VCF data (with ancestral state annotations from PopHuman), producing tab-delimited per-gene MKT count tables that feed the iMKT web service or R package.

## When to use

Use when population-genomic variation data are provided as VCF (e.g. 1000GP Phase III via PopHuman) and per-gene polymorphism/divergence counts for an unfolded SFS are needed to run MK-derived tests such as the eMKT.

## When NOT to use

- Working with Drosophila data in FASTA format from PopFly/DGN — the 02_Human pipeline and VCF-based workflow do not apply; use the 01_D. melanogaster pipeline instead
- Input is already pre-computed MKT count tables (DAF/divergence data frames) — skip processing and call iMKT functions directly
- The goal is de novo variant calling or ancestral-state inference rather than counting polymorphism/divergence for MK tests

## Inputs

- 1000GP Phase III VCF files with variant ancestral-state information, retrieved from PopHuman
- Human-chimpanzee divergence data from PopHuman
- 1000GP pilot mask (accessible genome masks) from the 1000 Genomes FTP to exclude low-quality variants
- Gene transcript annotations for assigning genes and functional classes (0-fold/4-fold)

## Outputs

- Tab-delimited file per gene and population containing the unfolded site frequency spectrum (DAF-binned Pi and P0), analyzable sites by largest transcript, and divergence counts
- Counts stratified by MKT functional classes (0-fold: selected class; 4-fold: neutral class)
- daf and divergence data frames directly consumable by iMKT R package functions (e.g. standardMKT, eMKT)

## How to apply

Retrieve genome-wide variation data plus ancestral-state information generated by the 1000GP Phase III, together with human-chimpanzee divergence, from PopHuman in Variant Call Format (VCF). Apply the 1000GP pilot mask from the accessible_genome_masks FTP directory to exclude low-quality variants before counting. Run the human pipeline (python/bash, Jupyter notebook 02_Human pipeline) from the iMKTData repository, which returns a tab-delimited file with the unfolded site frequency spectrum, analyzable sites by largest transcript, and divergence per gene, population, and MKT functional class (0-fold = selected class; 4-fold = neutral class). These count tables can then be loaded into the iMKT R package as 'daf' and 'divergence' data frames, or uploaded to the iMKT web service, to estimate alpha and other selection regimes. The pipeline requires the conda environment imktData.yml and was developed on a 100GB RAM / 16 Xeon CPU server.

## Related tools

- **Python** (Implements the 02_Human pipeline (python/bash) that parses 1000GP VCFs and computes unfolded SFS and divergence counts per gene and population)
- **bash** (Raw scripts in the iMKTData src/ folder execute the parallelized VCF processing steps of the human pipeline)
- **Jupyter** (Notebooks running on a Python 3.6 kernel execute the pipeline step by step (notebooks/humanProteins.ipynb)) — https://nbviewer.jupyter.org/github/jmurga/iMKTData/blob/master/notebooks/humanProteins.ipynb
- **iMKT (R package)** (Consumes the resulting daf and divergence data frames to perform MK-derived tests and estimate alpha) — https://github.com/BGD-UAB/iMKT

## Examples

```
devtools::install_github("BGD-UAB/iMKT"); library(iMKT); standardMKT(myDafData, myDivergenceData)
```

## Evaluation signals

- Output is a tab-delimited file containing unfolded site frequency spectrum information, analyzable sites by largest transcript, and divergence by gene, population, and MKT functional class
- All variants falling outside the 1000GP pilot mask (accessible genome masks) are excluded before counting
- Counts are correctly partitioned into 0-fold (selected) and 4-fold (neutral) functional classes per gene
- Downstream iMKT calls (e.g. standardMKT on myDafData/myDivergenceData-style frames) run without schema errors and return an alpha estimate plus Fisher's exact test P-value
- For task_004-style validation: emkt_high_recombination_ceu_yri_results.tsv exists, contains alpha estimates for both CEU and YRI under both gene sets, and reproduces predominantly negative alpha values differing between gene groups

## Limitations

- Pipeline requires downloading large external files (1000GP Phase III VCFs, PopHuman divergence, Bhèrer et al. 2017 recombination data, pilot mask) and hardcoded paths must be changed locally
- Developed for a conda environment (imktData.yml) on a 100GB RAM, 16-core Intel Xeon server; multiple steps need parallelization via custom bash scripts or manual server runs
- Only raw code is provided; notebooks must run on a Python 3.6 kernel
