# weighted-unifrac-distance-computation

## Summary

Compute abundance-weighted, phylogeny-aware UniFrac distances between representative-sequence (feature) distributions produced by different denoising/clustering methods or against expected mock-community compositions, to quantify how faithfully each DC method recapitulates true community sequences.

## When to use

Use when comparing feature/OTU tables generated by alternative DC methods (vsearch closed/open/de novo at 0.97, DADA2, Deblur) on 16S data, or benchmarking a method against a known mock-community composition on a reference phylogeny.

## When NOT to use

- Input is raw reads with no feature/OTU table and reference phylogeny yet — the DC step and tree building must precede UniFrac computation
- The comparison depends only on presence/absence of low-abundance taxa and abundance weighting should be ignored — unweighted UniFrac is the appropriate metric instead

## Inputs

- Feature/OTU table (sample-by-observation abundances) in qiime2-compatible format from each DC method
- Representative sequences and phylogenetic tree (Greengenes gg_97 phylogeny)
- Expected (true) mockrobiota mock-community composition tables (mock4, mock12, mock16)
- Demultiplexed trimmed paired-end 16S reads (forward.fastq.gz, reverse.fastq.gz, barcodes.fastq.gz, mapping.tsv)

## Outputs

- unifrac_distances.csv — tidy table of weighted UniFrac distances with columns for mock set and DC method (or method-by-method averaged distances)
- Pairwise weighted UniFrac distance matrix between DC methods, averaged over samples

## How to apply

Build the sample-by-observation abundance profiles with phylogenetic information from each method's OTU/feature table (qiime2-compatible format after consensus chimera removal), then compute weighted UniFrac distances between all pairs of samples using QIIME2 or the scikit-bio UniFrac implementation on the Greengenes phylogeny (gg_97). For the mock-community evaluation (mockrobiota mock4, mock12, mock16), compute the weighted UniFrac distance between each predicted representative-sequence distribution and the expected (true) mock-community distribution. Average pairwise distances over samples when comparing DC methods on a single study (e.g., the FMT Qiita study 10532 runs 2-4), and assemble results into a tidy table with columns for mock set and DC method written to unifrac_distances.csv. Weighted UniFrac is preferred when abundance differences matter; the paper found it revealed strong agreement among four methods with Deblur as the outlier, and identified DADA2 as the best-performing method on all mock data sets.

## Related tools

- **MiCoNE** (Pipeline that runs the five DC methods and produces the feature tables whose distributions are compared via weighted UniFrac) — https://github.com/segrelab/MiCoNE
- **qiime2** (Provides the feature-table format and UniFrac distance computation on the Greengenes phylogeny)
- **DADA2** (Denoising method whose feature table is benchmarked; best weighted UniFrac performance on all mock data sets)
- **Deblur** (Denoising method benchmarked; stands out as the weighted-UniFrac outlier on the FMT study data)
- **Python** (Used with scikit-bio to compute UniFrac distances and assemble the tidy distance table)

```
micone init -w <workflow> -o <pipeline_dir>; bash run.sh  # then compute weighted UniFrac on the resulting feature tables with qiime2/scikit-bio against gg_97
```

## Evaluation signals

- The weighted-UniFrac column of unifrac_distances.csv identifies DADA2 as having the lowest distance to the expected distribution across mock4, mock12, and mock16, matching Fig. 2C/D
- For the FMT study, the weighted-UniFrac comparison identifies Deblur as the outlier relative to the other four methods, reproducing Fig. 2A/B
- The unweighted-UniFrac dissimilarity is attributable to low-abundance sequences
- Distance table is tidy with explicit mock-set and DC-method columns and contains no missing method x mock combinations

## Limitations

- No single DC method outperforms the rest in all data sets — DADA2's advantage is specific to the mockrobiota mock sets evaluated
- Unweighted UniFrac differences can be driven by low-abundance sequences and do not necessarily indicate meaningful compositional disagreement
- Requires a trusted reference phylogeny (Greengenes); taxa absent from the reference cannot contribute meaningfully to phylogenetic distance
